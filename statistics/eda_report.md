## 2. Распределение классов

| Класс | Количество | Процент | Интерпретация |
|-------|------------|---------|---------------|
| -1 (Sell) | 257 | 5.10% | Сигнал на продажу |
| 0 (Neutral) | 4,545 | 90.14% | Нет сигнала |
| +1 (Buy) | 240 | 4.76% | Сигнал на покупку |

### 2.2 Анализ дисбаланса

```
⚠️ КРИТИЧЕСКИЙ ДИСБАЛАНС КЛАССОВ

Majority класс (0): 90.14%
Minority классы (-1, +1): 9.86% суммарно

Соотношение majority:minority ≈ 9:1
```

**Последствия:**
- Модели склонны предсказывать только majority класс
- Accuracy — бесполезная метрика (90% при предсказании только 0)
- Требуются специальные техники балансировки

**Рекомендации:**
1. Использовать **F1-score**, **AUC-PR** вместо accuracy
2. Применять **SMOTE**, **ADASYN** для oversampling
3. Использовать **class_weight='balanced'** в моделях
4. Рассмотреть **Focal Loss** для нейросетей

### 3.2 Ключевые наблюдения

1. **direction** — идеальный дискриминатор между -1 и +1:
   - Класс -1: всегда direction = -1

   - Класс 0: смешанное распределение

2. **impulse** — выше для minority классов:
   - Класс 0: mean = 2.58
   - Классы ±1: mean ≈ 3.8-4.0

3. **reverse** — выше для minority классов:
   - Класс 0: 45% имеют reverse=1
   - Классы ±1: 84-86% имеют reverse=1

4. **strong**, **break** — константы в fractal[0]:
   - Почти всегда равны 0
   - Могут быть информативны в других фракталах

## 4. Статистические тесты

### 4.1 Методология

- **Нормальность:** Shapiro-Wilk (n < 5000) / D'Agostino-Pearson (n ≥ 5000)
- **Тест различий:** Welch's t-test (для нормальных) / Mann-Whitney U (для остальных)
- **Effect size:** Cohen's d

### 4.2 Интерпретация Cohen's d

| |d| | Интерпретация |
|-----|---------------|
| < 0.2 | Незначительный эффект |
| 0.2 - 0.5 | Малый эффект |
| 0.5 - 0.8 | Средний эффект |
| ≥ 0.8 | Большой эффект |

### 4.3 Результаты тестов (избранные)

| Признак | Сравнение | p-value | Cohen's d | Effect Size |
|---------|-----------|---------|-----------|-------------|
| direction | -1 vs +1 | < 1e-100 | -∞ | Large |
| impulse | -1 vs 0 | < 1e-20 | 1.05 | Large |
| impulse | +1 vs 0 | < 1e-15 | 0.77 | Medium |
| reverse | -1 vs 0 | < 1e-30 | 0.95 | Large |
| reverse | +1 vs 0 | < 1e-25 | 0.90 | Large |
| count | -1 vs 0 | < 1e-5 | 0.17 | Negligible |

### 4.4 Важное замечание

```
⚠️ При малых размерах minority классов (n≈250) статистические тесты 
имеют ограниченную мощность. Cohen's d более информативен, чем p-values!
```
