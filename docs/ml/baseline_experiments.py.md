# Baseline Experiments Documentation

## Назначение
Скрипт `ML/baseline/baseline_experiments.py` предназначен для установления нижней границы качества (baseline) с помощью классических алгоритмов машинного обучения. Это позволяет оценить наличие предиктивного сигнала в данных перед использованием более сложных нейросетевых архитектур.

## Структура модуля
```
ML/baseline/
├── baseline_experiments.py   # Основной скрипт
├── plots/                    # Confusion matrices для каждой модели
└── reports/
    └── baseline_report.md    # Сгенерированный отчет с метриками
```

## Используемые модели
1. **Dummy Classifier** (stratified) — случайное предсказание с учетом распределения классов.
2. **Logistic Regression** — линейная модель на базовых признаках (`fractal[0]`, ATR, время).
3. **Random Forest** — ансамбль деревьев на базовых признаках.
4. **XGBoost** — градиентный бустинг на полном наборе из 233 извлеченных признаков.
5. **LightGBM** — быстрый градиентный бустинг на полном наборе из 233 извлеченных признаков.

## Входные данные
- **Файлы**: `DATA/Nero_train_labeled.csv`, `DATA/Nero_validation_labeled.csv`.
- **Признаки**:
  - `flat`: 11 полей фрактала 0 + ATR + синус/косинус часа и дня недели.
  - `engineered`: 233 признака, включая скользящие статистики, индикаторы тренда, моментум и волатильность.

## Выходные данные
- **Отчет**: `ML/baseline/reports/baseline_report.md`.
- **Графики**: `ML/baseline/plots/baseline_cm_*.png`.

## Использование
```bash
python ML/baseline/baseline_experiments.py
```

## Метрики
- **Macro F1-score** — основная метрика для оценки качества при сильном дисбалансе классов.
- **Accuracy**, **ROC-AUC (OVR)** — дополнительные метрики.
- **Classification Report** — полнота и точность по каждому классу.
