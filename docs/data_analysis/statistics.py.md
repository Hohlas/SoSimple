# Статистика и анализ данных (statistics.py)

## Назначение
Скрипт предназначен для потоковой обработки больших наборов данных (CSV) с финансовыми сигналами и фракталами. Он собирает статистику распределения признаков, баланса классов и генерирует выборки для дальнейшего обучения моделей.

## Входные данные
- **Файл**: `Nero.csv`
- **Формат**: CSV с разделителем `;`, содержит колонки `time`, `signal`, `predict`, `ATR` и набор колонок `fractalN`.
- **Источник**: Результат работы препроцессинга или разметки данных.

## Выходные данные
- **Файл**: `statistics_summary.json` — Основные метрики (среднее, std, квантили) для всех признаков.
- **Файл**: `class_balance_report.csv` — Отчёт о распределении целевой переменной (signal).
- **Файл**: `feature_distributions.csv` — Таблица распределений признаков в формате CSV.
- **Файл**: `nero_sample_stratified.csv` — Сбалансированная выборка, включающая все редкие события и подмножество нормальных.
- **Файл**: `class_statistics.json` — Детальная статистика по признакам первого фрактала в разрезе классов.

## Использование
```bash
python statistics/statistics.py
```

## Примечания
- **Метод Уэлфорда**: Используется для вычисления среднего и стандартного отклонения "на лету", что позволяет обрабатывать файлы любого размера без переполнения памяти.
- **Reservoir Sampling**: Применяется для получения репрезентативной выборки значений при расчёте квантилей, ограничивая потребление памяти.
- **Стратификация**: При создании `nero_sample_stratified.csv` сохраняются все сигналы (не-ноль) и добавляется случайная выборка нулевых сигналов для предотвращения перекоса модели в сторону мажоритарного класса.
