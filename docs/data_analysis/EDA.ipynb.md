## Ключевые функции

### Загрузка и парсинг данных

| Функция | Описание |
|---------|----------|
| `parse_fractal_string()` | Парсинг строки фрактала в словарь с 11 признаками. Возвращает `dict` или `None` при ошибке. |
| `load_nero_data()` | Загрузка и валидация CSV-датасета Nero. Возвращает `(raw_df, fractal_0_df, fractal_cols, n_fractals, time_col)`. |
| `parse_multiple_fractals()` | Парсинг нескольких фракталов для корреляционного анализа между позициями. |
| `parse_full_sequence()` | Преобразование данных в 3D тензор `(n_samples, n_fractals, 11)` для нейросети. |

### Статистический анализ

| Функция | Описание |
|---------|----------|
| `compute_feature_stats_by_class()` | Расчёт описательных статистик (mean, std, quantiles) по классам signal. |
| `check_normality()` | Тест на нормальность: Shapiro-Wilk для n<5000, D'Agostino-Pearson для больших выборок. |
| `cohens_d()` | Расчёт размера эффекта Cohen's d для оценки практической значимости различий. |
| `perform_statistical_tests()` | Попарные статистические тесты (t-test / Mann-Whitney U) между классами с коррекцией. |
| `analyze_outliers()` | Детекция выбросов методами IQR (1.5×IQR) и квантильным (1%-99%). |

### Визуализация

| Функция | Описание |
|---------|----------|
| `plot_histograms_by_class()` | Гистограммы распределений признаков с разбивкой по классам signal. |
| `plot_boxplots_by_class()` | Boxplot-диаграммы с notch для визуальной оценки значимости различий медиан. |

### Feature Engineering

| Функция | Описание |
|---------|----------|
| `engineer_sequence_features()` | Создание агрегированных признаков из последовательностей фракталов: тренды, статистики, паттерны. |

## Структура анализа

### 1. Загрузка и парсинг данных
- Чтение CSV с автоматическим определением временного столбца
- Парсинг первого фрактала (fractal[0]) для базового анализа
- Валидация обязательных столбцов: time, signal, predict, ATR

### 2. Анализ целевых переменных
- **signal** — дискретная метка {-1, 0, 1} с экстремальным дисбалансом
- **predict** — непрерывная метка (predict = -back × direction)
- **ATR** — волатильность рынка в момент формирования фрактала

### 3. Статистический анализ признаков
- Описательные статистики по каждому классу
- Гистограммы и boxplots для визуального сравнения
- Статистические тесты на значимость различий
- Оценка размера эффекта (Cohen's d)

### 4. Корреляционный анализ
- Корреляционные матрицы для каждого класса отдельно
- Кросс-корреляции между соседними фракталами
- Выявление мультиколлинеарности

### 5. Анализ выбросов
- Детекция методами IQR и квантильным
- Визуализация выбросов на boxplots
- Оценка влияния выбросов на статистики

### 6. Снижение размерности
- **t-SNE**: визуализация кластеров в 2D
- **PCA**: линейное снижение размерности, объяснённая дисперсия

### 7. Анализ последовательностей (n фракталов)
- Парсинг полной последовательности в 3D тензор
- Анализ временных паттернов по позициям фракталов
- Feature engineering на последовательностях

## Основные выводы

### 1. Дисбаланс классов
- **Класс 0 (Neutral)** доминирует в датасете (~95%+)
- **Классы -1 и 1** (Sell/Buy) — редкие события
- **Рекомендация**: использовать weighted loss, oversampling (SMOTE) или focal loss

### 2. Ключевые признаки (по размеру эффекта Cohen's d)

| Признак | Сравнение | Cohen's d | Интерпретация |
|---------|-----------|-----------|---------------|
| `back` | -1 vs 0 | Large | Сильное различие |
| `front` | 1 vs 0 | Medium | Среднее различие |
| `power` | -1 vs 1 | Medium | Различие между Sell и Buy |
| `reverse` | -1 vs 0 | Small-Medium | Информативен для Sell |

### 3. Корреляционные паттерны
- Сильная корреляция `front` ↔ `back` у соседних фракталов
- `power` и `count` сильно коррелируют (ожидаемо)
- `direction` антикоррелирует с `predict` (по определению)

### 4. Разделимость классов (t-SNE)
- Частичное разделение классов в пространстве сниженной размерности
- Класс 0 образует плотное облако в центре
- Классы -1 и 1 располагаются на периферии, но перекрываются

### 5. Выбросы
- Наибольшее количество выбросов в признаках `power`, `count`, `reverse`
- Выбросы могут соответствовать экстремальным рыночным событиям
- **Рекомендация**: не удалять, но использовать робастные методы или winsorizing

## Рекомендации для модели

### Архитектура
1. **Последовательная модель** (LSTM, GRU, Transformer) — данные имеют временную структуру
2. **Attention механизм** — для выявления наиболее информативных фракталов в последовательности
3. **Dual output** — предсказание и signal (classification), и predict (regression)

### Предобработка
1. **Нормализация**: StandardScaler или RobustScaler (из-за выбросов)
2. **Обработка дисбаланса**: class_weight, oversampling, или focal loss
3. **Feature selection**: отбор признаков с |Cohen's d| ≥ 0.5

### Валидация
1. **Временное разделение** — train/val/test по времени (уже реализовано в label_main.py)
2. **Метрики**: F1-score, ROC-AUC, Precision@K (из-за дисбаланса)
3. **Stratified sampling** — сохранение пропорций классов
