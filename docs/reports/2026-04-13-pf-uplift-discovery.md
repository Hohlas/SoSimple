## Контекст

Направление комбинирования `quantile × fav_3_vs_12` закрыто с вердиктом gate_fail: честная пересборка источника дала N=47 сделок вместо N=48, плюс отрицательный годовой срез в 2023. Это означает, что дополнительный фильтр почти ничего не добавляет к квантилю, но ломает годовую стабильность — усложнение не оправдано.

Нужно найти другие источники роста PF — вне ML-слоя: в логике входа, параметрах выхода, фильтрах по режиму рынка, логике советника. Цель — не переобучать, а найти то, что уже есть в данных и в структуре сигнала.

---

## Что сделано

- **Воспроизведён базовый уровень**: внутреннее соединение seed_007 × базовая модель даёт N=48 квантильных сделок с PF=8.179 на тестовом периоде — точное совпадение с исходным числом
- **Сформирован список из 20 гипотез** по 5 категориям (R: режим рынка, S: параметры выхода, E: логика входа, F: фильтры по признакам, X: параметры советника); жёсткие запреты (MA/EMA, переобучение, разность цен закрытия) не нарушены
- **Размечены режимы**: реализованная волатильность (H1×24, сдвиг назад на 1 бар — без утечки будущего), торговая сессия по времени брокера, день недели — добавлены в trade_enriched.csv
- **Построена таблица распределения** паттерн × сессия × волатильность: найдено, что Азия = 100% выигрышных, убыточный паттерн в Нью-Йорке даёт PF=0.28
- **Выполнены 6 быстрых проверок** только на чтение: каждая проверяла прирост PF, сокращение числа сделок, убыточные годы
- **Проверка по траектории цены**: симуляция по OHLC побарно (окно 24 бара), для проверки времени удержания — сравнение траекторий к бару 12 и к бару 24
- **Отобраны 3 сильных гипотезы** из 6 проверенных по зафиксированному критерию (прирост PF > +0.3, N сокращается ≤ 30%, убыточные годы не появляются)
- **Созданы предварительные планы** для каждой из 3 отобранных гипотез

Нетривиальные решения:
- Воспроизведение N=48 потребовало точного повторения логики объединения таблиц (без предварительной фильтрации строк) — предварительная фильтрация давала N=18 вместо N=48
- Лондонская сессия уже = 0 в квантиле, поэтому гипотеза «исключить Лондон» автоматически стала неактуальной и была отброшена без проверки
- Список ограничен 3 гипотезами несмотря на 4 сильных кандидата — четвёртый (верхняя четверть волатильности, +2.42 PF) отложен как первый кандидат для комбинирования

## Выводы

**ОТОБРАНЫ 3 ГИПОТЕЗЫ** — все три сильные по зафиксированным критериям.

Три ортогональных механизма роста PF без переобучения:

1. **Нью-Йоркская сессия** (время, +12.1 PF): Азия = 100% выигрышных (N=19, PF=inf). Убыточный паттерн в Нью-Йорке даёт PF=0.28 — именно там сосредоточены провалы. Механизм: структура ликвидности и волатильности в Нью-Йорке усиливает нежелательное движение цены для убыточного паттерна.

2. **Ранний выход на баре 12** (длительность удержания, +5.55 PF): бары 13–24 не добавляют ценности — 0 выигрышных не переворачиваются, убыточные не восстанавливаются. Механизм чистый, N не меняется.

3. **Ограничение pred_adv12 ≤ Q75** (предсказанное нежелательное движение, +4.57 PF): модель точно предсказывает максимальный убыток в ходе сделки — разница в 4 раза (0.35 vs 1.38 ATR), соотношение профит/убыток 10x vs 1.2x. Механизм подтверждён через траекторию цены.

Все три гипотезы не пересекаются между собой и не конфликтуют с существующими направлениями исследований.

## Ограничения / Открытые вопросы

- **Только тестовый период**: все проверки — на тестовых данных. Пороги (Q75, бар 12, граница сессии) нужно фиксировать на проверочном периоде, а не на тестовом
- **Метки сессий**: зависят от часового пояса брокера — нужна проверка UTC-смещения и поведения при переводе часов
- **true_ret_12_dir_atr** для проверки раннего выхода — приближение (не учитывает конкретный путь цены побарно); реальный выход на баре 12 требует симуляции по OHLC
- **Нет многосидовой проверки**: проверки выполнены только на seed_007; многосидовая устойчивость проверяется на следующем шаге реализации
- **Аномалия в нижней четверти волатильности**: отрицательный максимальный убыток в ходе сделки в OHLC-симуляции — возможна ошибка в логике поиска по временным меткам; не устранено
- **Верхняя четверть волатильности (СИЛЬНАЯ #4)**: не попала в список из-за ограничения в 3 гипотезы, но рекомендуется как первый кандидат для комбинирования
