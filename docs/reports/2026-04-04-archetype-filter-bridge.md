# Связь фильтров качества с архетипами сигнала

> **Дата**: 2026-04-04
> **Статус**: Завершён
> **Цель**: Проверить, связаны ли два подтверждённых на holdout фильтра Variant 4 (`fav_3_vs_12 <= 0.653`, `ratio_3_vs_12 > 4.751`) с принадлежностью к выигрышному архетипу («плоский дрейф»), и определить, нужен ли вход на откате поверх фильтра
> **Связанные отчёты**: `2026-04-04-signal-path-atlas-readout.md`, `2026-04-04-signal-quality-filter.md`
> **Источник данных**: `API/signal_path_atlas.py`

## Контекст

Разбор атласа (2026-04-04) показал двумодальную структуру: 64% провал vs 36% плоский дрейф. Оба архетипа воспроизведены на holdout. Выигрышный архетип характеризуется минимальным ходом «против» (медиана 0.48 ATR) — эти сигналы почти не откатываются.

Variant 4 (2026-04-04) дал два подтверждённых на holdout фильтра, но их связь с архетипами не была проверена. Этот этап закрывает пробел.

## Методология

1. Загружены данные через конвейер атласа (те же даты разбиения).
2. Архетипы построены на discovery (кластеризация → 2 группы после объединения мелких), holdout-сигналы классифицированы через обученную модель.
3. Каждый фильтр применён к discovery и holdout, подсчитаны доли выигрышных/провальных.
4. Вход по рынку и вход на откате оценены через модель SL/TP (SL=5, TP=50).
5. Доля исполнения отложенных ордеров (на откате) разбита по архетипам.

Discovery: 1752 сигнала. Holdout: 851 сигнал.

|---|---|---:|---:|---:|---:|---:|
| Discovery | Без фильтра | 1752 | 627 | 35.8 | 1125 | 64.2 |
| Discovery | `fav_3_vs_12 <= 0.653` | 194 | 77 | 39.7 | 117 | 60.3 |
| Discovery | `ratio_3_vs_12 > 4.751` | 442 | 172 | 38.9 | 270 | 61.1 |
| **Holdout** | **Без фильтра** | **851** | **318** | **37.4** | **533** | **62.6** |
| **Holdout** | **`fav_3_vs_12 <= 0.653`** | **84** | **37** | **44.0** | **47** | **56.0** |
| **Holdout** | **`ratio_3_vs_12 > 4.751`** | **176** | **59** | **33.5** | **117** | **66.5** |

**Что видно:**
- `fav_3_vs_12 <= 0.653` повышает долю выигрышного архетипа: +3.9 пп на discovery, **+6.6 пп на holdout** (37.4% → 44.0%).
- `ratio_3_vs_12 > 4.751` **НЕ повышает** долю выигрышного архетипа: +3.1 пп на discovery, **-3.9 пп на holdout** (37.4% → 33.5%).
- Оба фильтра пересекаются на 8 (discovery) / 4 (holdout) сигналах — практически не связаны между собой.

| `ratio_3_vs_12 > 4.751` | выигрышный | 3ATR | 59 | 0 | 0.0 | — |

**Это ключевая таблица.** Она объясняет, как работает вход на откате на уровне архетипов:

- **Выигрышные сигналы почти не исполняются на откате.** Доля исполнения: 20% при 1ATR, 1.3% при 3ATR (без фильтра). С фильтрами при 3ATR — **0%**.
- **Провальные сигналы исполняются массово.** Доля исполнения: 84% при 1ATR, 27% при 3ATR.
- **PF на выигрышных = экстремально высокий** (8–25), но на единичных сделках.
- **PF на провальных = умеренный** (0.87–3.79) — это эффект лучшей цены входа.
- **Откат 3ATR + любой фильтр = ни одного выигрышного исполнения.** Все 25 сделок от `ratio_3_vs_12 > 4.751 + откат 3ATR` — провальные сигналы.

## Главные выводы

### 1. `fav_3_vs_12 <= 0.653` — единственный фильтр, связанный с выигрышным архетипом

На holdout: 44.0% выигрышных vs 37.4% без фильтра (+6.6 пп). Эффект воспроизводим на обеих выборках (discovery: +3.9 пп, holdout: +6.6 пп). Фильтр не идеален (56% отфильтрованных всё равно провальные), но это лучшее из доступного.

`ratio_3_vs_12 > 4.751` на holdout **ухудшает** состав по архетипам (33.5% выигрышных — ниже базовой линии). Его PF-эффект (1.73 при откате 1ATR) не связан с обогащением выигрышного архетипа — это чисто механическое улучшение цены.

### 2. Вход на откате при использовании фильтра практически бесполезен

- При 1ATR: доля исполнения выигрышных = 27% (fav фильтр) / 14% (ratio фильтр) — теряем более 70% выигрышных сигналов.
- При 3ATR: доля исполнения выигрышных = **0%** с обоими фильтрами.
- Выигрышные сигналы не откатываются (ход «против» медиана = 0.55 ATR). Вход на откате для них — нерабочий механизм.

### 3. Рост PF при откате идёт за счёт провальных сигналов, не выигрышных

Вход на откате (даже без фильтра) исполняет 84% провальных vs 20% выигрышных. Рост PF — это **улучшение цены входа на провальных сигналах + редкие, но очень прибыльные выигрышные исполнения**. Это хрупкая конструкция.

### 4. Лучшая комбинация: `fav_3_vs_12 <= 0.653` + вход по рынку

| Вариант | N (holdout) | % выигр. | PF |
|---|---:|---:|---:|
| Без фильтра + по рынку | 850 | 37.4 | 1.04 |
| `fav_3_vs_12 <= 0.653` + по рынку | 84 | 44.0 | 1.78 |
| `fav_3_vs_12 <= 0.653` + откат 1ATR | 43 | 23.3 | 2.64 |
| `ratio_3_vs_12 > 4.751` + по рынку | 176 | 33.5 | 0.81 |
| `ratio_3_vs_12 > 4.751` + откат 1ATR | 103 | 7.8 | 1.73 |

`fav_3_vs_12 <= 0.653` + вход по рынку:
- **PF = 1.78** — существенно выше базовой линии (1.04) и ratio + по рынку (0.81)
- **N = 84** — достаточно для оценки направления, но не для точной оценки PF
- **44% выигрышных** — лучший состав по архетипам среди всех вариантов
- **Откат поверх этого фильтра ухудшает долю выигрышных** (с 44% до 23%) при повышении PF (2.64) за счёт улучшения цены — это компромисс: выше PF, но меньше сделок и хуже состав

### 5. Нужен ли вход на откате вообще?

**Ответ: нет, если используется фильтр `fav_3_vs_12 <= 0.653`.**

- Вход по рынку с этим фильтром даёт PF=1.78 на 84 сделках — это уже прибыльно без отката.
- Откат дал бы PF=2.64 на 43 сделках, но ценой потери ~50% объёма и **снижения доли выигрышного архетипа** с 44% до 23%.
- Откат 3ATR вообще не исполняет выигрышные сигналы (0 сделок).
- Откат имеет смысл только как самостоятельный способ улучшения цены (без фильтра), но тогда его преимущество не связано с отбором хороших сигналов.

**Если `ratio_3_vs_12 > 4.751` используется отдельно:**
- Вход по рынку не работает (PF=0.81)
- Откат 1ATR поднимает PF до 1.73, но это механический эффект, а не отбор выигрышных
- Этот фильтр **не рекомендуется** как основной фильтр для отбора по архетипу

## Ограничения и открытые вопросы

1. **N=84 для `fav_3_vs_12` + вход по рынку** — средняя выборка. Достаточна для вывода о направлении эффекта, но для точной оценки PF нужно больше данных.
2. **Фильтр `fav_3_vs_12 <= 0.653` не идеален** — 56% отфильтрованных сигналов остаются провальными. Это обогащение, а не разделение.
3. **Почему `ratio_3_vs_12 > 4.751` улучшает PF при откате, не обогащая выигрышный архетип?** Возможное объяснение: фильтр убирает самые быстрые и глубокие провалы (которые уходят «против» сразу и далеко), оставляя «медленные» провалы, на которых лимитный ордер исполняется по лучшей цене и даёт положительный результат. Это не отбор по архетипу, а фильтрация по тяжести провала.
4. **Погодовая устойчивость `fav_3_vs_12`** в Variant 4 показала ухудшение 2022→2024 с восстановлением на holdout. Устойчивость на более длинных выборках не доказана.
5. **Оба фильтра не связаны** (пересечение 8/4 сигнала). Комбинация не добавляет ценности.
