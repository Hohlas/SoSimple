# Product Requirements Document

## Цель
Создать автоматическую торговую систему на базе машинного обучения для рынка Forex (XAUUSD, H1):
1. Предобработка данных
2. Статистический анализ
3. Выбор архитектуры нейронной сети
4. Обучение нейронной сети
5. Бэктест
6. Интеграция с MT4

## Проблема
Существующие [PIC-паттерны](docs/dataset_description.md) (100 фракталов × 11 признаков) содержат потенциальные предиктивные сигналы, но требуют ML для обнаружения нелинейных зависимостей.


## Описание продукта
Система анализирует последовательности из 100 фракталов (паттерны Price in Channel). Прогнозируется вероятность разворота тренда и ожидаемое движение.


## Целевая аудитория
Разработчик проекта (я), НЕ production.

## Критерии успеха (MVP)

1. Точность модели: >65% на тестовой выборке
2. Sharpe Ratio: >1.5 на бэктесте
3. Максимальная просадка: <25%


## Функциональные требования

### Данные
- **Источник**: MetaTrader 4 (только котировки XAUUSD, H1)
- **Глубина истории**: 10+ лет
- **Тип данных**: [массив списков признаков фракталов](docs/dataset_description.md)

### Модель
- **Обучение**: Offline на исторических данных
- **Архитектура**: Выбирается на основе EDA
- **Outputs**: ([определение и формулы](docs/dataset_description.md#целевые-метки))
  - Classification: signal ∈ {-1, 0, 1}
  - Regression: predict ∈ [-1, 1] (нормализованное ожидаемое движение)

### Inference
- **Латентность**: не критична (>10 сек на прогноз приемлемо)
- **Интеграция**: MT4 через DLL или REST API
- **Частота**: ~1 раз в 60 мин (1 бар H1)


## Технические требования

### Stack
- **ML**: PyTorch, Scikit-learn (возможны изменения)
- **Preprocessing**: Pandas, NumPy
- **Integration**: Python ↔ MT4 (через DLL/REST)

### Нефункциональные требования
- **Логирование**: все прогнозы + актуальные результаты → CSV
- **Мониторинг**: метрики (опционально)


## Ограничения и риски

### Ограничения
- Нет учёта спредов/комиссий в модели (учитывается в бэктесте)
- Нет online learning (модель статична после обучения)

### Риски
- **Переобучение**: дисбаланс классов (95%+ класс 0)
  - Mitigation: weighted loss, SMOTE, focal loss
- **Data leakage**: важно соблюдать временное разделение
  - Mitigation: строгий train/val/test split по времени
- **Рыночные изменения**: модель может устареть
  - Mitigation: периодическое переобучение (каждые 6-12 мес)
