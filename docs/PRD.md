# Product Requirements Document

## Цель

Cоздание эффективного торгового алгоритма, использующего машинное обучение для анализа рыночных паттернов и получение прибыли от его использования. 

## Задача ИИ агента

- Выбор архитектуры нейронной сети на основе анализа входных данных.
- Автоматизация процессов тестирования и развертывания.

## Критерии успеха

- **Точность модели**: >65% на тестовой выборке
- **Sharpe Ratio**: >1.5 на бэктесте
- **Максимальная просадка**: <15%
- **Win Rate**: >55%

## Функциональные требования

- Inference модели: таймфрейм (H1), требования к быстродействию прогнозов не предъявляются
- Интеграция модели с MT4 через DLL/REST API
- Режим обучения offline (не online learning) на исторических данных более 10лет.
- Данные только из котировок MT4 (нет альтернативных источников), один торговый инструмент
