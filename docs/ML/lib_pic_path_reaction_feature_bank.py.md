# lib_pic_path_reaction_feature_bank.py

## Назначение

Строит производные признаки исторической реакции цены после уровней `lib_PIC`.

Этот слой дополняет geometry-bank: geometry описывает форму уровня, а path-reaction описывает, как цена уже реагировала на прошлые уровни через `Up/Dn`.

## Входные данные

DataFrame с колонками:

```text
fractal0 ... fractal99
```

Ожидаемый текущий формат фрактала — 22 поля:

```text
T:P:Dir:Frnt:Back:Strong:Brk:Rev:Pwr:Cnt:Imp:Up12:Dn12:Up24:Dn24:Up48:Dn48:Up3:Dn3:Up6:Dn6:FractalAtr
```

## Выходные данные

Копия исходного DataFrame с добавленными колонками вида:

```text
pic_path_fav24_mean_w20
pic_path_adv24_recent_w5
pic_path_edge48_mean_w50
pic_path_rr12_recent_w10
pic_path_win_proxy24_share_w100
```

Окна по умолчанию:

```python
(5, 10, 20, 50, 100)
```

`fractal0` считается самым свежим фракталом.

## Логика направления

Для фрактала с `Dir > 0`:

- благоприятный ход (`fav`) = `Up`;
- неблагоприятный ход (`adv`) = `Dn`.

Для фрактала с `Dir < 0`:

- благоприятный ход (`fav`) = `Dn`;
- неблагоприятный ход (`adv`) = `Up`.

Так признаки описывают реакцию цены относительно направления уровня, а не просто абсолютные `Up/Dn`.

## Признаки

Для горизонтов `3/6/12/24/48` и окон `5/10/20/50/100` строятся:

- средний/максимальный/свежий благоприятный ход;
- средний/максимальный/свежий неблагоприятный ход;
- edge = `fav - adv`;
- rr = `fav / adv`;
- доля уровней, где `fav > adv`;
- наклоны реакции между 3 и 48 барами;
- наклоны реакции между 12 и 48 барами.

## Временная корректность

`Up/Dn` не считаются заглядыванием вперёд, если они накоплены только по барам, уже известным на момент строки. Это закреплено в `docs/DATA_FLOW.md`.

Этот модуль не пересчитывает `Up/Dn`; он только строит признаки из уже экспортированных значений.

## Ограничения

- Это генератор признаков, не торговый benchmark.
- Он не доказывает прибыльность сам по себе.
- Перед включением в обучение нужна validation-first проверка.
