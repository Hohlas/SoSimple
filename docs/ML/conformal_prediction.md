## Что такое Conformal Prediction

Split Conformal Prediction — математическая надстройка поверх любой модели, которая превращает точечные предсказания в калиброванные доверительные интервалы.

**Гарантия:** истинное значение попадает в интервал с вероятностью ≥ (1−α). Не эвристика, а математическое свойство.

**Применительно к проекту:** вместо `pred_up_12 = 0.45` модель выдаёт `[0.23, 0.67]` с вероятностью 90%.

---

## Реализация

### Метод: Split Conformal (Nonconformity Score = |y_true − y_pred|)

1. Прогон модели на validation set → `y_pred` shape `(N, 6)`
2. Вычисление residuals: `scores = |y_true − y_pred|` на каждый из 6 таргетов
3. Квантиль уровня `(1−α)(1+1/n)` per target → 6 чисел (finite-sample correction)
4. Сохранение в `ML/conformal/conformal_quantiles.json`

## Вывод: почему CP не помогает при θ=2.665

### Причина 1: Split Conformal даёт глобальные (не per-sample) интервалы

Квантиль — одно число для всех примеров. Фильтр `pred_up > q_up` отсекает примеры с малой абсолютной величиной предсказания, но это не коррелирует с качеством сигнала.

### Причина 2: θ=2.665 уже крайне агрессивный фильтр

Порог θ пропускает только 2203 сделки из 9342 (23.6%). Внутри этой группы модель ошибается лишь в 14% случаев. CP нечем фильтровать — оставшиеся ошибки не предсказуемы глобальным квантилем.

### Аналогия из трейдинга

Это как добавлять фильтр объёма к стратегии, которая уже торгует только при Volume > 10×average. Дополнительный фильтр уберёт несколько случайных хороших сделок, но не добавит ценности.

---

## Где CP имел бы смысл

| Сценарий | Ожидаемый эффект |
|----------|-----------------|
| **Более мягкий θ (1.5–2.0)** | Больше borderline сигналов → CP фильтрует шум |
| **Управление размером позиции** | Ширина интервала как confidence score → позиция пропорциональна уверенности |
| **Conformalized Quantile Regression (CQR)** | Модель обучается выдавать квантили → per-sample адаптивные интервалы. Требует переобучение |
| **Adaptive Conformal Inference (ACI)** | Квантиль пересчитывается скользящим окном → адаптация к рыночным режимам |

## Используемый фильтр в коде

```python
# Magnitude filter в API/generate_signals.py
if conformal_quantiles:
    q_up = conformal_quantiles['up_12']
    q_dn = conformal_quantiles['dn_12']
    # Отменяем BUY если pred_up < q_up (маленькое абсолютное предсказание)
    signals[(signals == 1) & (pred_up < q_up)] = 0
    signals[(signals == -1) & (pred_dn < q_dn)] = 0
```

Логика: отсекать «шумовые» сигналы, где ratio велик лишь потому что обе стороны близки к нулю.
