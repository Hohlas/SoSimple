# label_signals.py

## Назначение
Логика маркировки данных: вычисление целевых переменных `signal` и `predict` на основе будущих фракталов.

## Входные данные
- **Вход**: DataFrame с отсортированными фракталами.
- **Данные**: Строки фракталов в формате `time:price:direction:...`

## Выходные данные
- **Модифицированный DataFrame**: Заполненные колонки `signal` и `predict`.

## Ключевые функции
- `label_all(input_path, output_path, debug=False)`: Основная функция маркировки.
- `find_fractal_by_time()`: Поиск фрактала в будущем (Forward-looking).
- `label_signals()`: Расчёт сигналов (входов).
- `label_predict_only()`: Расчёт предсказаний (выходов).

## Логика маркировки
1. Для каждой строки анализируются "будущие" строки (так как данные исторические).
2. Осуществляется поиск ближайшего сильного фрактала.
3. Рассчитывается `signal` (направление входа) и `predict` (цель движения).
4. Учитывается направление целевого фрактала (`direction`).

## Примечания
- Использует "заглядывание в будущее" (look-ahead) только для формирования обучающей разметки.
- Не должен использоваться при инференсе (торговле) без флага `labels=False` (если применимо).
