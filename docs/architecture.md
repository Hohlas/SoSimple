# Архитектура проекта SoSimple

## Обзор

Проект посвящен разработке автоматизированной торговой системы на базе нейронной сети. Проект состоит из следующих основных этапов:

1. Сбор данных из MetaTrader-4 и формирование массива фракталов (MQL4) 
2. Сортировка нормализация и маркировка (Python)
3. Статистический анализ (Python, Jupyter Notebooks)
4. Обучение моделей (ML)
5. Тестирование (ML)
6. Развертывание (ML)   


## Структура проекта

## Pipeline проекта и компоненты

### 1. Структурирование котировок
**Компонент**: `MT/MQL4/Include/lib_PIC.mqh`  
**Назначение**: Структурирует ценовые экстремумы (фракталы) в упорядоченный массив признаков  
**Входные данные**: `котировки OHLC терминала MetaTrader4` 
**Выходные данные**: `Nero.csv` (структура в `dataset_description.md`)

### 2. Предобработка данных
**Компоненты**: Скрипты в `processing/`  
**Назначение**: Сортировка, нормализация, маркировка, обработка выбросов, разделение на выборки  
**Входные данные**: `Nero.csv`  
**Выходные данные**: 
- `Nero_normalization_stats.csv` — статистика признаков
- `Nero_atr_scaler.pkl` — RobustScaler для ATR
- `Nero_train_labeled.csv` — обучающая выборка
- `Nero_val_labeled.csv` — валидационная выборка
- `Nero_test_labeled.csv` — тестовая выборка

### 3. Статистический анализ
**Компоненты**: `statistics/statistics.py`, `statistics/EDA.ipynb`  
**Назначение**: 
- До предобработки: выявление аномалий и оптимизация параметров
- После предобработки: оценка качества данных и выбор модели  
**Входные данные**: `statistics/Nero.csv`  
**Выходные данные**: Отчёты и графики в `reports/`, `plots/`, `EDA_files/`
