# План исследования: улучшение Profit Factor и качества сигналов

## Цель
Повысить Profit Factor выше 1.0 и улучшить качество торговых сигналов путем комбинации улучшения данных, функций потерь, архитектур и методов пост-обработки.

## Шаги исследования

### 1. Углубленный анализ данных и feature engineering
- [ ] Анализ распределения признаков и целевых переменных (|predict|, signal)
- [ ] Добавить вейвлет-признаки (CWT/DWT) для выделения краткосрочных и среднесрочных паттернов
- [ ] Добавить спектральные характеристики (энергия по полосам, энтропия)
- [ ] Добавить циклические компоненты (час дня, день недели, месяц)
- [ ] Добавить волатильность на разных таймфреймах (стандартное отклонение ATR за N периодов)
- [ ] Добавить взаимодействия между фракталами (например, отношения цен, разности направлений)
- [ ] Провести отбор признаков через mutual information и L1-regularization (Lasso)
- [ ] Оценить важность признаков через SHAP values

### 2. Тестирование простых и надежных моделей как baseline
- [ ] SVM с RBF ядром и классовыми весами для классификации и регрессии (SVR)
- [ ] LightGBM с оптимизацией через Optuna (фокус на F1-minority для классификации, Pearson r для регрессии)
- [ ] Логистическая регрессия с L1/L2 регуляризацией
- [ ] Сравнение метрик с текущими нейросетями на том же наборе признаков

### 3. Исследование функций потерь
- [ ] Реализовать асимметричную loss function (Custom Trading Loss) для регрессии:
  * Сильнее штрафовать недопрогноз крупных движений (например, вес 10 для ошибок, когда y_true > y_pred и y_true > порог)
  * Экспериментировать с различными асимметричными коэффициентами
- [ ] Тестировать Quantile Loss для предсказания specific quantiles (например, 0.9 для крупных движений)
- [ ] Сравнить с текущим HuberLoss и Focal Loss
- [ ] Оценить влияние на распределение предсказаний и Profit Factor

### 4. Исследование новых методов ML и анализа данных
- [ ] Конформное прогнозирование:
  * После обучения модели вычислить неп conformity scores на валидационном наборе
  * Для тестовых примеров построить интервалы предсказаний с гарантированным покрытием
  * Торговать только когда интервал не пересекает ноль или имеет достаточный отступ
  * Оценить влияние на Profit Factor и количество сделок
- [ ] Ансамблирование и стекинг:
  * Обучить несколько базовых моделей (Bi-LSTM, SVM, LightGBM)
  * Использовать их предсказания как мета-признаки для финальной модели
  * Оптимизировать веса стекинга на валидационном наборе, максимизируя Profit Factor
- [ ] Анализ нестационарности и режиме-переключения:
  * Разбить данные на окна (по годам) и оценить стабильность метрик
  * Если метрики сильно варьируют, рассмотреть обучение на скользящем окне
  * Использовать скрытые марковские модели (HMM) для определения режимов и обучения отдельных моделей для каждого режима

### 5. Методы уменьшения ложных сигналов и калибровка
- [ ] Оптимизация порога θ для преобразования регрессионных предсказаний в торговые сигналы:
  * Максимизировать Profit Factor вместо F1 или accuracy
  * Использовать кросс-валидацию по времени для выбора порога
- [ ] Применить методы калибровки вероятностей для классификации:
  * Platt scaling
  * Isotonic regression
  * Оценить калибровку через reliability diagrams и Brier score
- [ ] Исследовать методы отклонения низкоуверенных прогнозов:
  * Использовать энтропию предсказаний или margin как меру уверенности
  * Устанавливать порог уверенности для фильтрации сигналов

### 6. Обновление документации и планов
- [ ] Добавить результаты экспериментов в docs/plans/ (например, отчеты по каждому этапу)
- [ ] Обновить AGENTS.md и CHANGELOG.md с описанием проведенных работ
- [ ] Сохранить лучшие модели и скрипты в соответствующих директориях

## Ожидаемые результаты
- Profit Factor > 1.0 на тестовой выборке
- Улучшение стабильности модели (снижение дисперсии метрик при разных сидах)
- Снижение доли ложных сигналов (повышение precision/recall для классов -1 и 1)
- Подготовка к интеграции с MT4 после достижения целевых метрик

## Критерий завершения
Достижение Profit Factor > 1.0 и F1-minority > 0.45 на тестовой выборке с использованием предложенных методов.

## Последующие шаги
После завершения этого плана рассмотреть:
- Онлайн обучение или периодическое переобучение
- Интеграцию с MT4 через DLL/REST API
- Бэктест с учетом спредов и комиссий
- Live trading в режиме симуляции
