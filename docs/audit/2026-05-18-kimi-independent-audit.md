## 1. Резюме

Проведён независимый аудит цепочки от сырых данных до frozen test. Обнаружены **4 критические ошибки**, **3 структурных слабости** и **1 протокольное нарушение**. Установлено, что текущий результат (Test PF=1.23) достигнут преимущественно за счёт случайного совпадения с bull-режимом золота на test; SELL-направление систематически убыточно и хуже случайного выбора.

**Главный вывод**: Устойчиво достичь `validation PF > 2.0` на текущих признаках и таргете невозможно. Необходимы коренные изменения: (а) переход к BUY-only как interim baseline, (б) внедрение regime-aware признаков, (в) замена trailing-profit таргета на более стабильный, (г) использование нейросетевого энкодера вместо RF на табличных признаках.

## 3. Критические ошибки (доказаны)

### 3.1. Протокольное нарушение: frozen test запущен не для validation winner

**Доказательство**:
- `summary.json` содержит winner: `D_hgb_buy0.30_sell0.60_m0.05_standalone` (HGB, one-sided, balance=0.09).
- `frozen_test.json` содержит config: `D_rf_buy0.40_sell0.60_m0.10` (RF, balanced).
- План требует: "Select the single best validation winner... freeze its configuration and run **one** frozen test."

**Последствия**: результаты frozen test не соответствуют строгому протоколу. HGB был отброшен как one-sided (верно), но frozen test запущен для другой конфигурации без явной документации выбора.

### 3.2. SELL модель хуже случайного выбора

**Доказательство**:
- Random SELL precision baseline = 1745/9415 = **0.185**.
- Model SELL precision = 129/843 = **0.153**.
- Разница: **−0.032** (модель генерирует anti-signal).

**Последствия**: SELL сигналы не просто «слабые» — они активно вредят. Каждая SELL сделка, отобранная моделью, имеет матожидание хуже, чем если бы направление выбиралось случайно.

### 3.3. Инверсия калибровки SELL-модели

**Доказательство**:
- SELL prob [0.5, 0.7): win_rate = 0.413, mean_ret = −0.596.
- SELL prob [0.7, 1.0]: win_rate = **0.376**, mean_ret = **−0.583**.
- Более высокая confidence → более низкий win rate. Модель **инвертирована** для SELL.

**Последствия**: пороговая логика для SELL работает наоборот. Чем увереннее модель в SELL, тем вероятнее убыток.

### 3.4. BUY модель лишь немного лучше случайного

**Доказательство**:
- Random BUY precision = 2416/9415 = **0.257**.
- Model BUY precision = 340/1202 = **0.283**.
- Edge: +0.026 (~10% относительно).
- Recall = 14.1% (модель находит лишь 1/7 всех возможных хороших BUY).

**Последствия**: BUY сигнал существует, но крайне слабый. Модель не умеет отличать хорошие BUY от плохих.

## 4. Структурные слабости

### 4.1. Признаки не несут направленческой информации

**Доказательство**:
- Top-20 feature importance для BUY и SELL моделей **практически идентичны**: `nearest_02_impulse`, `nearest_00_front`, `nearest_03_front`, `nearest_02_front`, `nearest_01_back`.
- `fractal0_direction` — **20-е место** (importance ~1.5%).
- Модель использует одни и те же геометрические паттерны для обоих направлений, не различая их.

**Вывод**: feature builder не создаёт направленчески-специфичных признаков. Признаки описывают «структуру вокруг уровня», но не «куда пойдёт цена».

### 4.2. Таргет (Target D, trailing profit) чрезмерно шумный

**Доказательство**:
- BUY precision = 28.3%, но recall = 14.1%. 86% хороших BUY модель пропускает.
- SELL precision = 15.3%, recall = 7.4%. 93% хороших SELL модель пропускает.
- Trailing stop срабатывает случайно из-за внутридневной волатильности; 24-баровый горизонт пересекается с рыночным шумом.

**Вывод**: trailing profit — слишком «жесткий» таргет. Модель обучается на шуме, а не на сигнале.

### 4.3. Регимная нестабильность

**Доказательство**:
- Test period начинается с конца 2022 (начало bull run золота).
- SELL PF по месяцам 2022 (test): октябрь 0.000, ноябрь 0.256, декабрь 0.066.
- BUY PF по годам: 2022 = 0.65, 2023 = 1.09, 2024 = 2.49, 2025 = 2.00, 2026 = 2.62.
- Модель **не адаптирована к regime change** внутри одного года.

**Вывод**: статическая модель на 15-летнем train не переносится на резкий regime shift.

## 5. Анализ цепочки данных

### 5.1. Сырые данные (Nero.csv)
- **Asymmetry**: `up_24 > dn_24` в 54.3% случаев на test (uptrend bias). На горизонте 48 баров — 55.6%. Это объективное свойство рынка в период 2022–2026.
- **Fractal0.direction**: 52.5% UP, 47.5% DOWN. Но trailing-profit target asymmetry сильнее.

### 5.2. Таргет (Target D)
- Trailing profit симметричен по построению, но рынок **не симметричен**.
- SELL trailing stop срабатывает быстрее в bull market, потому что adverse move (рост цены) превышает trail_n × ATR.
- Результат: SELL target имеет меньшую positive rate, чем BUY, даже при симметричной логике.

### 5.3. Признаки (nearest_k4)
- 97 признаков, но топ-признак имеет важность всего 1.87%.
- Распределение важности равномерное (нет доминирующих признаков).
- Признаки не включают: временные паттерны, momentum, volume/volatility regime, макро-контекст.

### 5.4. Модель (RandomForest)
- RF с 160 деревьями, min_samples_leaf=20. Это консервативная настройка, но признаки не дают достаточно signal для разделения.
- HGB показал схожие результаты, что подтверждает: проблема не в модели, а в данных/таргете.

## 7. Что нужно исправить

### Обязательно (критические)
1. **Пересмотреть процедуру выбора winner**: frozen test должен строго соответствовать validation winner или явно документированной причине отклонения.
2. **Отказаться от SELL сигналов в текущей архитектуре**: SELL модель хуже случайного. Включение SELL в комбинированную стратегию снижает PF с 1.90 до 1.23.
3. **Заменить trailing-profit таргет**: шумный таргет не позволяет модели достичь разумной precision.

### Улучшить/дополнить
4. **Добавить regime-aware признаки**: volatility regime, trend strength, time-based features.
5. **Использовать fractal0_direction явно**: текущий feature builder его игнорирует (20-е место).
6. **Внедрить rolling validation**: проверять стабильность на скользящих окнах, а не на одном split.
7. **Использовать основной Transformer энкодер**: обученный regression_updn имеет r=0.56 по 10 таргетам; его hidden representations могут дать сильные признаки.

## 8. Новые варианты (выход за рамки предыдущего плана)

### 8.1. BUY-only с улучшенным входом
- Отказ от SELL как отдельного класса.
- Обучение одной модели: BUY vs SKIP.
- Ожидаемый эффект: устранение анти-сигнала SELL, рост PF с 1.23 до ~1.5–1.9.

### 8.2. Regime-aware ensemble
- Добавление признака «режим рынка»: bull / bear / ranging на основе скользящей трендовой силы.
- Обучение отдельных моделей для каждого режима или использование regime как признака.
- Ожидаемый эффект: адаптация к 2022 regime shift, снижение просадки в transition periods.

### 8.3. Transformer-based feature extractor
- Использование предобученного `transformer_updn_best.pt` для извлечения hidden representations.
- Поверх энкодера — лёгкий классификатор (BUY/SKIP).
- Ожидаемый эффект: использование temporal patterns из 20-фрактальной последовательности, недоступных табличному RF.

### 8.4. Alternative target: directional close
- Target = sign(Close[t+24] − Close[t+1]) при |return| > threshold × ATR.
- Проще, менее шумный, чем trailing profit.
- Ожидаемый эффект: более высокая разделимость классов.

### 8.5. Conformal Prediction для SELL
- Если SELL всё же нужен — использовать conformal prediction для калибровки confidence.
- Инверсия калибровки (higher confidence → lower win rate) может быть исправлена через CP.
- Ожидаемый эффект: корректная оценка uncertainty, возможность фильтрации плохих SELL.

## 10. Заключение

Текущий результат (Test PF=1.23) — это **верхняя граница возможностей табличной RF-модели на геометрических признаках с trailing-profit таргетом**. SELL-направление не просто слабое — оно **систематически убыточно**. BUY-направление имеет edge (+10% к precision), но недостаточный для достижения PF>2.0.

**Рекомендованный следующий шаг**: Phase A — BUY-only baseline с alternative target и regime-aware признаками. Phase B — Transformer feature extractor. Phase C — финальный frozen test только если validation PF > 2.0 и sequential PF > 2.0 стабильны на rolling windows.

Если Phase A не даёт validation PF > 1.5 — честный вердикт: текущая постановка задачи (fractal-level direction prediction на H1 XAUUSD) не позволяет достичь PF>2.0 без новых источников данных (например, order flow, макро-ивенты).
