## Контекст
Этот проект по разработке торговой системы ведется более года, проведено огромное количество исследований, написаны библиотеки кода и куча отчетов. Но положительные результаты, подходящие для продакшена так и не получены.
Нужно провести мозговой штурм (брэйншторм) по поиску новых подходов и прибыльных алгоритмов. При этом необходимо опираться/оглядываться на уже пройденные этапы, проведенные исследования и результаты. Для поиска новых идей ии агенту-брейнштормеру нужен контекст с бэкграундом проекта в сжатом виде.

## Описание задачи
С этой целью  потребовалось создать файл-ретроспективу проекта за весь период разработки. Он должен включать в себя описание пройденных этапов и результаты всех проведенных исследований в кратком лаконичном виде, чтобы минимизировать контекст ии агента-брэйнштормера.
Проект включает в себя огромное количество отчетов в docs/reports и ML/reports, а так же CHANGELOG.md по docs/reports.
Для составления ретроспективы /reports/retrospective.md создан скрипт-оркестратор docs/audit/retrospective-workflow.js. Изучи его и прокоментируй, насколько он соответствует поставленной задаче.
При необходимости, предложи варианты корректировки скрипта.

## Требования к /reports/retrospective.md:
- должен быть лаконичным, точным, без повторов.
- должен содержать краткую информацию о всех проведенных исследованиях и полученных результатах.
- не должен содержать второстепенную информацию о багах, подробности комитов, ...

## Требования к скрипту docs/audit/retrospective-workflow.js:
- размер контекстного окна используемых субагентов ограничен 150К
- использование graphify и knowledge-rag для оптимизации поиска и навигации по проекту
