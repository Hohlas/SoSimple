# docs/audit/

Рабочие методики и аудит-планы для проверки ML-моделей торговых систем.

| Артефакт | Роль | Когда обновлять |
|---|---|---|
| [`ml_trading_methodology.md`](ml_trading_methodology.md) | Универсальная методика разработки и аудита ML-моделей ТС в рамках проекта | Меняются обязательные gates, leakage-инварианты, схема validation/test/forward или выводы по типовым ошибкам |

## Правила

- Методики должны быть применимы к нескольким исследовательским трекам, а не к одному конкретному checkpoint.
- Примеры из проекта допустимы, но решения нельзя переносить без проверки по первичным файлам.
- Если методика ссылается на отчёты, выводы должны быть проверены по `docs/reports/`, а не только по wiki.
