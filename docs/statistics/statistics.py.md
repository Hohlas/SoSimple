# statistics.py

## Назначение
Потоковая обработка и сбор статистики по фракталам и сигналам из датасета Nero.csv. Обеспечивает анализ больших CSV-файлов без полной загрузки в память.

## Входные данные
- **Файл**: `statistics/Nero.csv`
- **Формат**: CSV с разделителем `;`
- **Колонки**: `time`, `signal`, `predict`, `ATR`, `fractal0`...`fractal99`

## Выходные артефакты

В процессе анализа в каталоге `statistics/` создаются следующие файлы:

### Основная статистика (statistics.py)
- **statistics_summary.json** — сводная статистика по всем признакам (mean, std, min, max, квантили) для фракталов, predict и ATR.
- **class_balance_report.csv** — отчет о балансе классов `signal` {-1, 0, 1}.
- **feature_distributions.csv** — распределения всех признаков в формате CSV для импорта в таблицы.
- **nero_sample_stratified.csv** — стратифицированная выборка (100% редких событий + 10% нормальных) для быстрого тестирования.
- **class_statistics.json** — детальная статистика признаков первого фрактала (`fractal0`) в разрезе классов.

### Визуализация и расширенные отчеты
- **каталог plots/** — графики в формате PNG:
  - Распределения признаков и боксплоты по классам.
  - Матрицы корреляций и тепловые карты статистических тестов.
  - Анализ временных рядов (ATR, сигналы во времени).
  - Проекции PCA и t-SNE для визуализации кластеризации.
- **каталог reports/** — сгенерированные документы:
  - `EDA_report.md` — детальный отчет по результатам разведочного анализа данных.
- **sequence_analysis_report.md** — —автоматически генерируемый— отчет об анализе последовательностей фракталов. Содержит:
  - Оценку качества данных (пропуски, нарушения причинности).
  - Рейтинг важности признаков (Feature Importance).
  - Рекомендации по архитектуре модели.

## Алгоритмы

### Метод Уэлфорда (Welford's algorithm)
Онлайн-расчёт среднего и дисперсии без хранения всех значений в памяти:

```python
# Для каждого нового значения x:
n = n + 1
delta = x - mean
mean = mean + delta / n
delta2 = x - mean
M2 = M2 + delta * delta2
variance = M2 / (n - 1)
```
## Преимущества:

- Константная память O(1)
- Численно стабильный
- Подходит для streaming данных

### Reservoir Sampling
Несмещённая выборка для квантилей без загрузки всех данных:

```python
# Резервуар размера k
if len(reservoir) < k:
    reservoir.append(value)
else:
    j = random(0, n)  # n — количество увиденных элементов
    if j < k:
        reservoir[j] = value
```
## Преимущества:

- Каждый элемент имеет равную вероятность k/n попасть в выборку
- Память O(k), независимо от размера данных
- Подходит для расчёта квантилей

## Обработка чанками
Файл обрабатывается порциями (chunksize=500), что позволяет:

- Работать с файлами больше RAM
- Показывать прогресс обработки
- Распределять нагрузку во времени

```python
# Пример:
chunks_reader = pd.read_csv(filepath, sep=';', chunksize=500)
for chunk in chunks_reader:
    stats.update(chunk, parsed_fractals)
```

## Стратифицированная выборка
Цель: Сохранить редкие события (signal ≠ 0) для детального анализа

Метод:
1. Собрать 100% строк с signal ∈ {-1, 1}
2. Собрать случайную выборку 10% от signal = 0
3. Объединить и перемешать

Применение: Использовать для быстрого EDA без загрузки всего датасета

## Статистика по классам
Для каждого класса signal анализируется первый фрактал (fractal0):

- Mean, std, min, max по каждому из 11 признаков
- Количество элементов в классе
- Процент от общего количества

Цель: Выявить различия между классами на уровне ближайшего фрактала
