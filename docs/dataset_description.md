# Описание входных даннных для обучения

Набор данных Nero_train_labeled.csv представлен в виде входного тензора X ∈ R^{k×n×11}, где каждая из k выборок — это событийно-ориентированный (event-driven) срез рыночной ситуации по последним n фракталам.


## Cтруктура файла

```bash
< строка заголовков >
time[0];signal[0];predict[0];ATR[0];fractal[0][0];fractal[0][1];…;fractal[0][n-1]
time[1];signal[1];predict[1];ATR[1];fractal[1][0];fractal[1][1];…;fractal[1][n-1]
. . .
time[k];signal[k];predict[k];ATR[k];fractal[k][0];fractal[k][1];…;fractal[k][n-1]
```

k > 6000  (количество строк в файле)
n = 100 (количество фракталов в строке)
time[i] - время формирования нового фрактала (человекочитаемая дата/время)
signal[i] - сигнал для обучения модели (значения добавляются при маркировке данных). 
predict[i] - сигнал для обучения модели (значения добавляются при маркировке данных).
ATR[i]-значение Average True Range в момент формирования нового фрактала 
fractal[i][0] .. fractal[i][n-1] - массив списков параметров ‘n’ фракталов.


## Структура списка параметров фрактала

Фракталом будем называть ценовую формацию из трех бар, в которой цена меняет свое направление: 
пик - средний бар выше предыдущего и последующего, 
впадина - средний бар ниже предыдущего и последующего. 
Каждый список ‘fractal[i][j]’ содержит параметры отдельного фрактала, разделённые ‘:’ и имеет следующую структур

```bash
fractal_time : price : direction : front : back : strong : break : reverse : power : count : impulse 
```

Фракталы в пределах строки упорядочены по fractal_time (fractal[i][0]-новый; fractal[i][n-1]-самый старый). 
ВАЖНО:  Из списка (строки) каждый раз "выпадает" не самый старый fractal[i][n-1], а самый слабый по критерию значимости (определяется алгоритмом).
Данные в пределах файла отсортированы по fractal_time первого фрактала - новые фракталы в конце файла.
Разделитель столбцов (фракталов) - ';'
Разделитель параметров фрактала - ':' 


## Значения параметров фрактала

### Временные данные:
- fractal_time (int) – Абсолютное время фрактала в секундах.
### Ценовые данные:
- price (float) – Значение цены пика фрактала.
- direction (int ∈ {-1, 1}) – Направление разворота фрактала. 1-пик, -1-впадина.
### Морфологические данные (форма и структура ценового движения вокруг фрактала):
- front (float) – Величина ценового движения до фрактала.
- back (float) – Величина ценового движения после фрактала.
- reverse (float) – Cила пробитого этим фракталом уровня. Если фрактал ничего не пробил, reverse=0.
- impulse (float) – Импульс цены (скорость разворота), который задал данный фрактал.
### Топологические данные (взаимное расположение и связи фракталов):
- power (float) – Сумма сил всех фракталов, совпадающих с этим фракталом по уровню.
- count (int) – Количество совпадений по значению цены с остальными фракталами.
### Бинарные и счетные флаги:
- strong (bool) – Признак разворота ценового тренда на данном фрактале. Определяется задним числом по историческим данным. strong=0 для fractal[i][0]
- break (int) – Счетчик, сколько раз фрактал был пробит последующими ценовыми движениями.


## Целевые метки 

Столбцы signal и predict содержат forward-looking информацию для обучения предсказательной модели supervised learning. Они формируется ретроспективно, post-factum, по уже сформированному csv файлу, анализируя будущую эволюцию фрактала fractal[i][0].
- signal={-1,0,1} Если  в будущем фрактал получит признак strong=1 (разворот тренда), ему присваивается значение signal=±1. Большинство строк имеют signal=0.  Значения signal формируют несбалансированный датасет, поскольку  являются редкими по определению. 
- predict={-p..p} получает значение признака back этого фрактала на момент его пробития с учетом знака: predict = -back * direction. Если фрактал не был пробит (break=0), то берется значение back этого фрактала на момент окончания файла, либо последнее значение back до момента его "выпадания" из списка. 

### Направление: 
- Sell: signal=-1; predict<0 -  если этот фрактал имеет признак direction=1(пик)
- Buy: signal=1; predict>0 - если этот фрактал имеет признак direction=-1(впадина)


## Свойства признаков фракталов

Структура данных представляет собой event-driven time-series snapshots:

- Строка i формируется в момент времени t_i при появлении нового фрактала fractal[i][0]
- Каждая строка — это immutable snapshot (неизменяемый снимок) рыночной ситуации на момент t_i, содержащий только информацию, доступную в этот момент
- Все n фракталов в строке i получают значения признаков на основе исторических данных до момента t_i включительно (causal consistency)
- Эволюционирующие признаки НЕ создают train/inference mismatch. В обучающей выборке fractal[i][0] имеет те же начальные значения признаков, что и новый фрактал в реальной торговле.
- После записи строки i её содержимое никогда не изменяется
- В строке h (h > i) тот же физический фрактал может присутствовать как fractal[h][k] с обновлёнными признаками, рассчитанными на момент t_h, отражающими накопление новой рыночной информации


Признаки делятся на:
1. СТАБИЛЬНЫЕ (не меняются после формирования фрактала):
   - fractal_time, price, direction, front, impulse, reverse
   
2. ЭВОЛЮЦИОНИРУЮЩИЕ (обновляются с появлением новых рыночных данных):
   - back (меняется при новых движениях после фрактала)
   - break (увеличивается при пробитии уровня)
   - strong (может измениться с 0→1 если фрактал станет сильным разворотом)
   - power, count (пересчитываются относительно новых фракталов)
