# docs/superpowers/

Краткая навигация по планам и проектным материалам исследовательских задач.

| Путь | Назначение |
|---|---|
| [`roadmap.md`](roadmap.md) | Исторический порядок крупных направлений исследования. Текущее состояние см. в [`../../CONTEXT_HANDOFF.md`](../../CONTEXT_HANDOFF.md). |
| [`plans/`](plans/) | Исполнимые планы задач: чеклист действий, затрагиваемые файлы, проверки и ожидаемые артефакты. |
| [`specs/`](specs/) | Проектные решения до реализации: контекст, выбранный подход, альтернативы и риски. |

## Правила

- Перед выполнением многошаговой задачи сначала читать связанный план из `plans/`.
- Перед изменением подхода читать связанную спецификацию из `specs/`, если она есть.
- Завершённые результаты фиксировать в `docs/reports/`; планы не заменяют отчёты.
