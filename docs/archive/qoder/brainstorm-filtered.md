# Брейншторм: отфильтрованный список

Дата: 2026-08-17. Арбитраж по протоколам споров «автор × критик» (docs/audit/brainstorm-protocols.md).
Первоисточник проверки цитат: docs/audit/retrospective.md, секции 2 и 4. Цитаты критиков по убитым идеям сверены с ретроспективой и описывают те же механизмы edge.

Вердиктов «выживает» нет ни у одной идеи — короткий список добран из «условно» (не более 10), строго по убыванию потенциала.

## 1. Короткий список выживших

### 1. Онлайн-детекция смены режима — потенциал 2/5, «условно», [спекуляция]
Суть: Bayesian online change-point detection (BOCPD/CUSUM) на статистиках ряда явно детектирует переломы; торговля только в устоявшихся стабильных фазах, смена режима — сброс моделей. Механизм edge («платят медленно адаптирующиеся участники») — [гипотеза].
Обходимый тупик: режимный дрейф и перелом 2023 (2.8: расширение обучения не спасает) — дрейф становится явной переменной состояния.
Убивающий эксперимент: предвыбранная конфигурация детектора фиксируется только на данных до 2018; гейт применяется к пайплайну 2.8 (trail_atr_0_2, спред 0.4); оценка на замороженном 2023–2026 против двух контролей: без гейта и случайный гейт равного duty cycle. Детектор применяется к остаткам после hour-baseline и ATR-нормализации (защита от календарной сезонности).
Метрика: PF на 2023–2026 с bootstrap CI (нижняя граница); PF гейта против PF случайного гейта.
Пороги убийства: нижняя граница bootstrap CI PF ≤ 1.0; PF с гейтом ≤ PF случайного гейта; >4 change-points в год или стабильные фазы покрывают <30% баров.
Стоимость: 2–3 дня.
Примечание: единственная идея с задокументированным прибыльным носителем в стабильной фазе (2.8: val_select 2019–2022 PF 2.041, 0 убыточных лет) — гейт не умножает ноль. Валидационная мощность ограничена одним переломом за ~20 лет.

### 2. Амплитудный стрэддл без знака — потенциал 2/5, «условно», [радикальная], [спекуляция]
Суть: в окнах срабатывания замороженного амплитудного фильтра (SHA-256, simple_combined/H3/top5%, 2.11) выставлять BUY STOP и SELL STOP с OCO-логикой и забирать реализованное движение без предсказания знака. Механизм «платят защитные стопы за уровнями консолидации» в OHLC непроверяем — [гипотеза].
Обходимый тупик: MI direction FAIL (2.1) — знак не используется; нужен только подтверждённый амплитудный режим (MI amplitude PASS p=0.005).
Убивающий эксперимент: ступень A — идеализированный payoff OCO-стрэддла от next-open на замороженном фильтре, стоп-дистанции d из предвыбранной сетки {0.25, 0.5, 1.0} ATR, спред 0.4/slippage 0.2 и стресс 0.8. Ступень B (если A пройдена) — полная симуляция с единым контрактом внутрибаровой хронологии fill, дельта против time+ATR базиса, погодовой разбор.
Метрика: средний чистый payoff на событие (A); PF с bootstrap CI и дельта против time+ATR базиса (B).
Пороги убийства: A — payoff ≤ 0 при всех d на спреде 0.4 либо ≤ 0 при лучшем d на спреде 0.8; B — PF < 1.3 или нижняя граница bootstrap CI ≤ 1.0, либо CI дельты против time+ATR базиса содержит 0, либо любой год 2023–2026 даёт PF < 1.0.
Стоимость: ступень A ~1 день, ступень B ещё 2–3 дня.
Примечание: знако-свободный payoff в проекте не тестировался (2.7 конвертировала пробой только в знакозависимые сделки) — не дубликат. Центральный риск: 57% строк H3 уже прошли ≥50% движения к моменту сигнала (2.11). Вариант той же механики, что идея №3 ниже.

### 3. Амплитудный OCO-стрэддл — потенциал 2/5, «условно», [радикальная], [спекуляция]
Суть: парные разнонаправленные отложенные ордера (OCO-стрэддл) при прогнозе режима высокого движения; направление разрешает рынок, трейлинг-выход снимает движение в любую сторону.
Обходимый тупик: MI direction FAIL и already-moved (2.11) — знак не прогнозируется вовсе.
Убивающий эксперимент: ступень A (дешёвый киллер) — медианная доля already-moved от полной амплитуды окна на горизонтах H3/H6 для строк с активным фильтром; ступень B — полный OCO-бэктест с плечами ±k·ATR, честной внутрибаровой хронологией fill, спредами 0.4 и 0.8 на frozen 2022-12..2026-06.
Метрика: медианная доля already-moved (A); PF с издержками + нижняя граница bootstrap CI (B).
Пороги убийства: A — медианная доля ≥ 0.5 (остаток не покрывает стоп-дистанцию + 2×спред); B — PF < 1.3 при спреде 0.4 или нижняя граница bootstrap CI ≤ 1.0.
Стоимость: 2–3 дня.
Примечание: близкий вариант механики идеи №2 — рекомендуется рассматривать как один эксперимент с общим kill-контуром. Автор признал, что «already-moved снимается конструктивно» — преувеличение: конструктивно снимается только знак.

### 4. Hawkes-каскады интенсивности движений — потенциал 2/5, «условно», [радикальная], [спекуляция]
Суть: крупные бары M5+ как события самоподдерживающегося точечного процесса (Hawkes); интенсивность предсказывает всплески без знака. Механизм «каскады стопов и ликвидаций» для FX без централизованного стакана признан спекулятивным.
Обходимый тупик: предсказание направления (MI direction FAIL) — интенсивность событий без знака; кластеризация смягчает проблему малых N.
Убивающий эксперимент: ступень 1 (без торговли) — события = бары M5 с |движением| > 2×ATR, оценка Hawkes на train 2004–2019, сравнение OOS log-likelihood 2020–2026 с тремя базисами: однородный Пуассон, неоднородный Пуассон по hour/dow, Пуассон от скользящего ATR. Ступень 2 — интенсивность как режимный гейт поверх замороженного движение-фильтра 2.11, а не самостоятельный беззнаковый вход.
Метрика: доля улучшения log-likelihood, захваченная календарным базисом; коэффициент ветвления n по подпериодам; PF с bootstrap CI.
Пороги убийства: календарный/ATR-базис захватывает ≥90% улучшения правдоподобия над Пуассоном; n(train) отличается от n(2020+) более чем на 30%; n OOS ≤ 0.1 (самоподдержки нет); в ступени 2 — PF < 1.3 при спреде 0.4 или нижняя граница bootstrap CI ≤ 1.0.
Стоимость: 2–4 дня.
Примечание: точного дубликата нет (EDA: индекс дисперсии 44.46 — описательный факт, не механизм); оценка ядра не хрупка по N (десятки тысяч событий при пороге 2×ATR).

### 5. Необратимость временного ряда — потенциал 2/5, «условно», [радикальная], [спекуляция]
Суть: перестановочная энтропия и статистики time-reversal на паттернах баров детектируют участки, где ряд отличим от обращённого во времени; edge ищется условно на них. Механизм «вынуженный поток платит» экономически реален, но ненаблюдаем напрямую на спот-Forex.
Обходимый тупик: тупик направления при нулевом глобальном MI — необратимость может существовать локально и условно.
Убивающий эксперимент: предрегистрированный измерительный тест: ordinal patterns D=4 на каузальном окне W∈{64,256}; бар необратим, если расхождение частот прямых/обращённых паттернов выше 95-го перцентиля суррогатов, сохраняющих амплитуду |r| но разрушающих знак. Контроль — амплитудно-согласованные суррогаты.
Метрика: условная MI(direction) внутри помеченных участков (бит); PF и нижняя граница bootstrap CI; доля отклика детектора, объясняемая амплитудными суррогатами.
Пороги убийства: условная MI(direction) ≤ 0.008 бит; доля помеченных баров < 1%; нижняя граница bootstrap CI PF ≤ 1.0; суррогаты объясняют ≥ 80% отклика детектора.
Стоимость: 2–4 дня.
Примечание: ordinal patterns инвариантны к монотонным преобразованиям амплитуды — не тривиальный дубликат movement-фильтра; главный риск — детектор первым обнаружит волатильностную кластеризацию (нулевую модель), а не направленный сигнал.

### 6. Мультифрактальный отпечаток режима — потенциал 2/5, «условно», [радикальная], [спекуляция]
Суть: скользящий мультифрактальный спектр (MFDFA) и показатель Хёрста как компактный отпечаток амплитудного режима; торгуется тип режима (персистентный vs антиперсистентный) с привязанными к нему параметрами сделок.
Обходимый тупик: low R² точечной регрессии — модель не претендует на предсказание среднего движения.
Убивающий эксперимент: дешёвый пре-тест — корреляция Хёрст/ширины спектра с ATR; затем строго каузальный скользящий MFDFA с замороженными на val_select 2019–2022 порогами, бенчмарк — стратегия режима hour+ATR-квантиль с идентичной механикой, перестановочный тест меток, спреды 0.4/0.8, bootstrap CI.
Метрика: OOS PF с bootstrap CI (нижняя граница); ΔPF против hour+ATR-бенчмарка; перестановочный p; |ρ| спектра/Хёрста с ATR.
Пороги убийства: пре-тест |ρ| с ATR > 0.7 (аппарат — избыточная переупаковка ATR); PF < 1.3 или нижняя граница bootstrap CI ≤ 1.0; ΔPF против hour+ATR-бенчмарка < +0.15; перестановочный p ≥ 0.05.
Стоимость: 2–3 дня.
Примечание: точного дубля нет (проверено knowledge-rag); условие выживания — прохождение пре-теста коллинеарности до полного прогона.

### 7. Детектор смены режима как триггер — потенциал 2/5, «условно», [радикальная], [спекуляция]
Суть: BOCPD/CUSUM обнаруживает переход между состояниями волатильности/дрейфа; вход — по первому импульсу после детектированной смены, трейлинг-выход. Механизм «кто платит» признан автором слабым.
Обходимый тупик: режимный перелом 2023 и межгодовой дрейф — смена режима как источник сигнала, а не угроза валидации.
Убивающий эксперимент: этап A — параметры детектора фиксируются строго на 2019–2022; event-study по каждой детектированной смене: доля ATR-нормированного импульса, уже пройденная к бару детекции, и частота продолжения в сторону импульса за вычетом спреда 0.4. Этап B — бэктест на frozen 2023–2026, вход на open следующего бара, стресс-спред 0.8, bootstrap CI (10k ресемплов).
Метрика: медианная доля пройденного импульса; частота продолжения нетто-спред; PF и нижняя граница bootstrap CI; число сделок в год.
Пороги убийства: медианная доля пройденного импульса >50%; частота продолжения ≤52% при спреде 0.4; PF <1.3 или нижняя граница bootstrap CI ≤ 1.0 при спреде 0.4; PF <1.0 при стресс-спреде 0.8; событий <100.
Стоимость: 1–2 дня.
Примечание: содержательный аргумент защиты — единственный стабильный edge проекта (амплитудный фильтр) сам есть реакция на уже случившееся движение (2.11); автор принял убивающий тест без изменений. Тематически пересекается с идеей №1, но механизм иной (триггер входа vs гейт стабильных фаз).

### 8. Относительная стоимость пар — потенциал 2/5, «условно», [радикальная], [спекуляция]
Суть: одновременные длинная и короткая позиции в двух коррелированных парах (EURUSD против GBPUSD); цель — относительное движение спреда пар, направленная экспозиция гасится. Механизм уточнён автором до стационарности спреда, а не «потоков».
Обходимый тупик: прямое предсказание направления в абсолютной постановке — относительный знак проектом никогда не проверялся (MI-аудит 2.1 измерял информацию признаков об абсолютном знаке одной пары).
Убивающий эксперимент: трёхступенчатый скрин без ML: (1) арифметика издержек — распределение |Δs| спреда на горизонте 12–24 бара против round-trip издержек двух ног; (2) ADF-тест спреда отдельно на train ≤2022 и test 2023–2026 + скользящая годовая корреляция; (3) примитивная z-score mean-reversion (|z|>2, выход z≈0) на строгом OOS с двумя спредами и bootstrap CI.
Метрика: 75-й перцентиль |Δs| в пипсах; p-value ADF на test; PF с учётом двух спредов + нижняя граница bootstrap CI.
Пороги убийства: round-trip издержки (~0.8–1.6 пипса) превышают 75-й перцентиль |Δs|; ADF p > 0.10 на test-периоде; PF < 1.3 или нижняя граница bootstrap CI ≤ 1.0 на 2023–2026.
Стоимость: 2–3 дня.
Примечание: данные GBPUSD в проекте есть (DATA/Nero_GBPUSD_*); автор честно оценивает априорную вероятность прохождения как низкую.

### 9. События исполнения как сигнал — потенциал 2/5, «условно», [радикальная], [спекуляция]
Суть: накопленная телеметрия исполнения (requote ERROR-138, задержки fill, корреляция fill_rate↔PF −0.46 из 2.13) как первичный сигнал: фильтр «не входить при лёгком филле» (adverse selection лимиток); реквотная нога вторична и помечена [гипотеза].
Обходимый тупик: внутрибаровая хронология fill и requote раньше считались помехой; аналога «исполнение как носитель сигнала» в ретроспективе нет.
Убивающий эксперимент: предрегистрированный event-study на уже накопленной телеметрии MT4-online и MT5-контура без новых live-прогонов: когорты «лёгких» и «тяжёлых» филлов с атрибутированным исходом; контроль календарём+ATR.
Метрика: PF когорты requote-входов и разность PF_easy − PF_hard с 95% bootstrap CI; AUC предсказания реквота по час+ATR.
Пороги убийства: событий с атрибутированным исходом < 200 (корпус не бэктестится); нижняя граница bootstrap CI PF requote-когорты ≤ 1.0; PF_easy ≥ PF_hard (нет штрафа adverse selection); AUC предсказания реквота из час+ATR ≥ 0.8 (события сводятся к календарю).
Стоимость: 1–2 дня.
Примечание: высокая вероятность гибели по порогу N<200 ещё до содержательной проверки; сигнал порождается инфраструктурой брокера и нестационарен.

### 10. Разногласие ансамбля как признак — потенциал 1/5, «условно», [спекуляция]
Суть: пропуск топ-20% строк по междусидовому разногласию (std предсказаний) на замороженном baseline A @ 7.5%; ветка сайзинга снята автором (доминируется наблюдаемым ATR и не двигает PF). Ожидаемый edge признан опровергнутым conformal-прецедентом (2.1), пока не доказано обратное.
Обходимый тупик: нестабильность автовыбора winner-правила — информационным носителем становится разнообразие моделей.
Убивающий эксперимент: замороженный ансамбль (5 сидов × 2 архитектуры, существующие чекпоинты, CPU-inference), одно правило до просмотра OOS; три гейта: G1 — прокси-проверка против ATR; G2 — направление фильтра; G3 — порог успеха.
Метрика: Spearman ρ(разногласие, ATR); PF пропущенного подмножества (PF_skip); ΔPF; итоговый PF с нижней границей bootstrap CI.
Пороги убийства: ρ ≥ 0.7; PF_skip ≥ 1.0 (повтор conformal-сценария: 15 из 16 отфильтрованных сделок прибыльны); ΔPF < +0.15; PF < 1.3 или нижняя граница bootstrap CI ≤ 1.0.
Стоимость: 2–3 дня.
Основание включения (тай-брейк среди 1/5): единственный проверенный новый факт во всех протоколах — conformal null-результат (2.1: PF 4.506→4.489) получен на leaky legacy up/dn-конфигурации, которую ретроспектива сама помечает как артефактную; переносимость неудачи «неопределённость → пропуск» на честный live-safe baseline A действительно неизвестна, и дешёвая перепроверка закрывает реальный пробел.

[нефальсифицируема] — таких идей нет: все протоколы содержат предрегистрированные kill-пороги.
