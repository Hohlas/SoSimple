#### Критическая проблема: Data Leakage в регрессии

**Проблема**: Directional Accuracy (DirAcc) = 97.5% — это артефакт обработки данных, а не реальная метрика.

**Корневая причина** ([`ML/data_loader.py`](../../../../../ML/data_loader.py), строки 269-271):
```python
# Regression: Убираем знак из predict (берем по модулю)
y_train = np.abs(df_train[target].values.astype(np.float32))
y_val = np.abs(df_val[target].values.astype(np.float32))
```

**Как это работает** ([`ML/utils.py`](../../../../../ML/utils.py), строка 145):
```python
dir_acc = float(np.mean(np.sign(y_true) == np.sign(y_pred)))
```

**Почему это не работает**:
1. `y_true` = abs(predict) → всегда положительный → sign(y_true) = 1 для всех samples
2. DirAcc = % предсказаний, где sign(y_pred) = 1 → % положительных предсказаний
3. Модели, предсказывающие mostly positive, автоматически получают ~97% DirAcc
4. Это НЕ означает, что модель правильно предсказывает направление!

**Вывод**: 
- ❌ DirAcc в текущем виде — бессмысленная метрика
- ❌ r = 0.55 (Pearson) — единственная осмысленная метрика для регрессии
- ⚠️ Необходимо пересмотреть формулу target для регрессии

### Приоритизированный план действий

#### 🔴 Приоритет 1: Исправить target для регрессии (CRITICAL)

**Проблема**: Текущий target = abs(predict) лишён направления.

**Решение A** (рекомендуется): Предсказывать sign отдельльно
```
1. Classification: signal ∈ {-1, 0, 1} → использовать текущую модель
2. Regression: |predict| ∈ [0, 1] → magnitude только
3. Финальный signal = classification_pred * sign(regression_pred)
```

**Решение B**: Предсказывать signed predict напрямую
```
1. Убрать np.abs() в data_loader.py
2. Использовать MSELoss вместо Huber
3. DirAcc станет осмысленной метрикой
```

**Решение C** (радикально): Убрать direction из features
```
1. Исключить fractal[0].direction из входных данных
2. Модель вынуждена учиться на других признаках
```

## Оценка реалистичности целей MVP

### PRD критерии успеха

| Критерий | Целевое | Текущее | Оценка |
|----------|---------|---------|--------|
| Accuracy > 65% | Classification accuracy | ~90% (но на majority class) | ⚠️ Недостоверно |
| Sharpe Ratio > 1.5 | Backtest | Требует test evaluation | ❓ Неизвестно |

### Реальные ожидания

| Метрика | Реалистичная цель | Оптимистичная цель |
|---------|-------------------|-------------------|
| Pearson r | 0.55-0.58 | 0.60-0.65 |
| MAE | 0.08-0.10 | 0.06-0.08 |
| R² | 0.25-0.35 | 0.35-0.45 |

### Для Sharpe > 1.5 потребуется:

1. **Реальная Direction Accuracy > 55%** (не текущие 97%)
2. **Profit factor > 1.5** на бэктесте
3. **Max drawdown < 25%**

Это требует:
- Качественной классификации направления (или signed regression)
- Правильного money management
- Учёта транзакционных издержек
