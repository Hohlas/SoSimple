The MT/ directory mirrors a full MetaTrader installation split into two parallel language targets: MQL4/ and MQL5/. Each target contains its own Experts/, Indicators/, Scripts/, Include/, Libraries/, Files/, and Profiles/ directories, so the same trading logic is maintained in both MQL4 and MQL5 variants. Shared cross-cutting concerns live in the Include/ subdirectories (e.g., MAIN.mqh, ORDERS.mqh, lib_ML_Signal.mqh, COUNT.mqh, ERRORs.mqh) which are duplicated between MQL4 and MQL5 to keep each platform self-contained. The tester/ directory holds Strategy Tester configurations (.set, .ini), CSV signal/trade-event outputs, and history files used by both platforms' backtesting workflows. Compiled binaries (.ex4/.ex5) sit alongside their .mq4/.mq5 sources, and Files/ stores runtime CSV artifacts (ml_signals.csv, ml_exits_*.csv, ML_Trade_Events_*.csv) consumed by external ML pipelines.
