Runs are driven through the MetaTrader 5 Strategy Tester GUI or command-line using the `.set` files in `files/`. Each test invocation produces a timestamped `SoSimple_<pid>.set` snapshot and corresponding `ML_Trade_Events_SoSimple_<pid>.csv` / `ERROR_SoSimple_<pid>.csv` pairs under `files/`. Optimization runs are configured via `opt.set` and `lastparameters.ini` (date range `from`/`to` timestamps).
