Flat collection of standalone MQL4 script files (`.mq4` source plus precompiled `.ex4` binaries) executed directly by the MetaTrader 4 terminal. Each script is self-contained with its own `OnStart()` entry point and uses MT4's built-in file I/O (`FileOpen`, `FileWrite`, `FileReadString`) or chart APIs (`Bars`, `Open`, `High`, `Low`, `Close`, `Volume`, `iATR`). The `Examples/DLL/` subdirectory pairs an `.mq4` tester with a C++ DLL project (`DLLSample.cpp`, `.def`, `.vcxproj`) compiled into `DLLSample.dll`, exposing functions via `#import`. The `Examples/Pipes/` subdirectory provides two named-pipe client implementations: one using the `CFilePipe` class from `<Files/FilePipe.mqh>` and another using raw `FileOpen`/`FileWriteInteger`/`FileReadString` calls against `\\.\pipe\MQL5.Pipe.Server`. There is no shared library — each script imports only standard MT4 headers and runs independently.
