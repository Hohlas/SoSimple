Scripts are launched directly from the MT4 Terminal's Navigator → Scripts panel on the desired symbol/timeframe. `ExportOHLC.mq4` writes CSV to `MQL4/Files/<SYMBOL>_<TF>_OHLC.csv` which must then be copied to `DATA/<SYMBOL>_<TF>_OHLC.csv`. `HistoryConvertor1002.mq4` reads a custom text input file specified by `InputFileName` and produces `History.csv`. `PeriodConverter.mq4` writes an offline `.hst` history file and watches for an offline chart window to update it live. The DLL example requires compiling `DLLSample.vcxproj` to produce `DLLSample.dll` in the same directory before running `DLLSampleTester.mq4`.
