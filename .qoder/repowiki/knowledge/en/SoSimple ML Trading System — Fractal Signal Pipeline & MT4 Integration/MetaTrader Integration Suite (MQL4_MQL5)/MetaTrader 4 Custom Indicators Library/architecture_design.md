Each indicator is a standalone .mq4 source file implementing the standard MQL4 entry points: `#property` directives declare window mode, buffers, colors, and inputs; `OnInit()` configures buffers via `SetIndexBuffer`/`SetIndexStyle`; `OnCalculate()` performs per-bar calculations; `OnDeinit()` cleans up chart objects. Indicators fall into two categories: (1) buffer-based line indicators that draw via `DRAW_LINE`/`DRAW_SECTION` (e.g., ATR, ZigZag, MACD, RSI, Stochastic, CCI, Momentum, Alligator, Heiken Ashi, Parabolic, OsMA); (2) object-drawing indicators that render text/lines directly on the chart using `ObjectCreate`/`ObjectSetText` without indicator buffers (e.g., iExposure, iVolumeCluster, SpreadCollector, MyTrades). The `Examples/SimplePanel/` subdirectory demonstrates MQL4 GUI via `CAppDialog` and the Controls library (`Controls\Dialog.mqh`, `Button.mqh`, `ListView.mqh`, etc.), with `PanelDialog.mqh` encapsulating the dialog class and `SimplePanel.mq4` wiring it as a zero-buffer indicator. Compiled `.ex4` binaries ship alongside sources, and `mqlcache.dat` holds the compiler cache.
