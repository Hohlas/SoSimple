Scripts are executed as Python modules: `python -m API.generate_signals`, `python -m API.export_entry_path_v1_signals`, `python -m API.telemetry_signal_watcher`, etc. The server is started via `uvicorn.run("API.api_server:app", host="127.0.0.1", port=8000)` from `api_server.py`. Telemetry watcher is typically run inside tmux with `--poll-interval-sec 1 --heartbeat-sec 60 --verbose`. Requires pre-trained checkpoints at `ML/checkpoints/transformer*_best.pt` and Optuna parameter JSONs at `ML/reports/`.
