Scripts are run directly, e.g. `python -m ML.baseline.baseline_experiments` or `./.venv/bin/python ML/baseline/benchmark_entry_based_powerful_tabular.py --entry-based-powerful-tabular --no-resume`. Each script expects pre-generated labeled CSVs under `DATA/` (e.g. `Nero_train_labeled.csv`, `Nero_validation_labeled.csv`) and engineered features under `statistics/`. Some scripts accept CLI flags like `--json-out` to write results.
