Each `.py` file is an independent executable script with its own `if __name__ == '__main__'` entry point; there is no shared package API. Scripts are organized by experiment theme: `baseline_experiments.py` runs the canonical 5-model classification benchmark; `benchmark_*.py` files explore specific hypotheses (fractal stops, limit-order entries, stage4/5/6 mechanics); `diagnose_*.py` and `audit_*.py` scripts inspect data alignment, walk-forward splits, and leaderboard robustness; `feature_ablation.py` and `rf_gridsearch.py` probe feature contributions and RF hyperparameters. Cross-cutting utilities live in sibling modules (`ML.data_loader`, `ML.experiment_logger`, `ML.benchmark_limit_order_entry`, `ML.feature_importance_diagnostics`) and are imported via `sys.path.insert`. Outputs are written to fixed directories under `ML/baseline/plots/` (PNG confusion matrices), `ML/reports/` (Markdown/JSON/CSV artifacts), and `DATA/` (spread-specific splits). The `mt5_signal_schema.py` module defines strict column schemas and time-order validators used by MT5 export scripts.
