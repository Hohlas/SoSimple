Five cohesive modules centered on transforming `fractalN` string columns (colon-delimited 23-field records) into numeric feature DataFrames:
- `fractal_level_feature_builder.py` is the core engine: `parse_fractal`/`parse_row_time`/`parse_fractal_time` decode raw strings; `build_zone_features` aggregates by ATR-relative price zones; `_build_nearest_k_features` selects the k closest fractals by |price|/ATR and emits slot-prefixed fields; `build_fractal_level_features` dispatches between `nearest_k`, `zones`, and `zones_plus_nearest_k` families. It also exposes `build_feature_contract` (a manifest of source_column/source_type/available_at/live_safe/model_input for audit) and a z-score normalizer (`fit_feature_normalizer` / `apply_feature_normalizer`).
- `multi_scale_fractal_features.py` takes a `(n, seq_len, feature_dim)` numpy tensor and concatenates per-window statistics (mean, std, last-minus-mean, slope, range) over windows `(5,10,20,50,100)`.
- `lib_pic_geometry_feature_bank.py` and `lib_pic_path_reaction_feature_bank.py` are parallel feature-bank modules that each parse fractal strings into tuples, compute rolling-window statistics over configurable windows, and join back to the input DataFrame under fixed prefixes (`pic_geom_`, `pic_path_`). Geometry features deliberately exclude Up/Dn fields to avoid look-ahead.
- `lib_pic_feature_profiles.py` orchestrates the above: it calls `build_grouped_features` from diagnostics, then assembles named profiles (`baseline_full`, `baseline_clean`, `baseline_full_path`, `baseline_clean_path`, `baseline_clean_geometry_path`) by concatenating baseline + optional path + optional geometry parts.
Dependency direction is one-way: profiles → geometry bank + path reaction bank; fractal-level builder is independent; multi-scale operates on numpy tensors downstream of any DataFrame-to-tensor conversion.
