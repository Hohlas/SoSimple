- Fractal records are parsed from colon-separated strings via dedicated `_parse_*` helpers that return None on malformed input, and callers treat None as missing rather than raising.
- Feature-bank modules expose a single public `build_lib_pic_*_feature_bank(frame, windows=...)` function that returns a copy of the input DataFrame joined with new columns under a fixed prefix constant (`GEOMETRY_FEATURE_PREFIX`, `PATH_REACTION_FEATURE_PREFIX`).
- Windowed features are generated by iterating over a tuple of window sizes (e.g. `(5,10,20,50,100)`) and naming columns with a `_w{window}` suffix so each window's feature set is self-describing.
- All floating-point outputs are sanitized through `.replace([np.inf, -np.inf], 0.0).fillna(0.0)` before being returned, ensuring downstream consumers never see NaN/Inf.
- Live-safety is declared per-feature via a structured dict in `build_feature_contract` listing `source_column`, `source_type`, `available_at`, `live_safe`, `normalization`, and `model_input`.
- Up/Dn horizon fields (3,6,12,24,48) are handled through explicit index maps (`UP_INDEX`, `DN_INDEX`) keyed by horizon rather than ad-hoc column names.
