Four sibling task modules, each exposing a small, self-contained API surface: a constant-driven column schema (e.g. `TAKE_SKIP_TRAILING_STOP_COLUMNS`, `TRAILING_STOP_TARGET_COLUMNS`), a `split_*_targets(df)` function that extracts and thresholds the relevant `trail_*_pnl_atr_x*` PnL columns into float32 labels, a `build_*_export_frame(...)` function that assembles a pandas DataFrame with `time`, `signal`, `pred_*`, and optional `true_*` columns, and an optional `compute_*_metrics(...)` function. The two classification tasks (`take_skip_trailing_stop_task.py` and `take_skip_trailing_stop_v2_task.py`) share an identical shape — v1 uses horizons `(2,3,4,6,8)` over a single 48-step horizon, while v2 cross-products three horizons `(12,24,48)` with three x-values `(2,4,8)` and additionally declares a fixed set of row-level features. The quantile task (`trailing_stop_target_quantile_task.py`) targets a single base column (`trail_48_pnl_atr_x3`) and outputs ordered q10/q50/q90 predictions plus pinball-loss, MAE, Pearson r, coverage, and interval-width metrics. All modules depend only on numpy/pandas and have no inter-module imports, making them independent plug-in tasks consumed by a higher-level ML pipeline.
