Flat pytest collection under `tests/` with one test file per production module or feature area; a small `processing/` subpackage mirrors the source's `processing/` namespace for tests that import it directly. Each test file is self-contained: it inserts `'.'` or `'processing'` into `sys.path`, builds synthetic pandas DataFrames / OHLC CSVs via helper functions (e.g. `_make_ohlc_csv`, `_make_nero_df`, `_fractal_str`), and asserts on output shapes, column names, or gradient flow. Tests are organized by concern rather than layer — benchmark suites (`test_benchmark_*`), export/validation scripts (`test_export_*`), stage-specific audits (`test_stage*_*.py`, `test_fractal0_*.py`, `test_trailing_stop_target_*.py`), and ML model shape/backprop checks (`test_entry_path_model.py`). The `processing/` subdirectory contains tests that import the sibling `processing/` package directly, keeping those tests close to the code they validate.
