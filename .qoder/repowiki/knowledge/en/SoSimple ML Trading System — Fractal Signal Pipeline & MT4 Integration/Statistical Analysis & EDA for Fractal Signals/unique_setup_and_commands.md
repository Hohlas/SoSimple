Requires activating the project venv (`source ~/git/SoSimple/.venv/bin/activate`). Run statistics via `python statistics/statistics.py DATA/Nero_train_labeled.csv`. Execute EDA notebook with `NERO_INPUT_PATH=../DATA/Nero_train_labeled.csv jupyter nbconvert --execute --to notebook --output EDA_executed --output-dir ./reports EDA.ipynb`. Signal tracer supports `--time`, `--batch --top N --min-ratio R --csv-out`, and `--from-log ... --losses-only --csv-out`. Data smoke check runs as `statistics/data_contract_smoke_check.py [--train|--val|--test]`.
