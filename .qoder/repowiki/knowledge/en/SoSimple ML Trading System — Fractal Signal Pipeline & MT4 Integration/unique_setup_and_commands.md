Standard Python venv setup: `python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`. The canonical entry point is `python processing/label_main.py --input MT/MQL4/Files/Nero.csv` to produce labeled datasets; the full pipeline then proceeds through ML training (`ML/train.py`), export (`API/generate_signals.py`), and live inference via `API/api_server.py` or `API/telemetry_signal_watcher.py`.
