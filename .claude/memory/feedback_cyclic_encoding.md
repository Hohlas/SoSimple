**Всегда объяснять причину нестандартного технического решения до его предложения.**
**Why:** При обсуждении кодирования часа пользователь предложил нормализовать в 0..1. Только после объяснения проблемы цикличности (23→0 разрыв, одно число не может кодировать позицию на цикле без неоднозначности) — принял sin/cos подход.
**How to apply:** Структура ответа: сначала "проблема которую это решает", потом "вот решение". Не "используем X потому что лучше", а "есть проблема Y, X решает её так-то".
