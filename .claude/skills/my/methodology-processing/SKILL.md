# Methodology Processing

Процессный скилл для ML-пайплайна.

## Порядок работы

1. Прочитай `docs/methodology/README.md` — найди свой этап по таблице «задача → файл»
2. Открой только файл этого этапа и придерживайся изложенных в нем инструкций.
3. Проверь обязательные критерии этапа
4. Зафиксируй статус (PASS / FAIL / UNKNOWN / DIAGNOSTIC_ONLY)
