Приоритет компактности документации для LLM:
- Одна мысль = одно предложение
- Избегай повторений между файлами
- Используй таблицы вместо списков для сравнений
- Максимум 250 строк на документ (кроме справочников)

Если документ > 300 строк:
1. Вынеси детали в отдельный файл
2. Оставь краткое резюме + ссылку
