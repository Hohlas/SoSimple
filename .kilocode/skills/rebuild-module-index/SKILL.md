# Регенерация MODULE_INDEX.md

Полная регенерация MODULE_INDEX.md из file headers всех кодовых файлов проекта.

**Когда использовать:**
- После массовых изменений в структуре проекта
- Когда MODULE_INDEX.md потерял синхронизацию с кодом
- После добавления нескольких новых модулей

---

## Формат записи в MODULE_INDEX.md

MODULE_INDEX.md использует **табличный формат** с разделами по директориям:

```markdown
## Processing

| Модуль | Назначение | Вход → Выход | Docs | Статус |
|--------|-----------|--------------|------|--------|
| [label_main.py](processing/label_main.py) | CLI оркестратор pipeline | `Nero.csv` → `*_labeled.csv` | [docs](docs/processing/label_main.py.md) | 🏁 |
```

**Легенда статусов**: ✅ Активный | 🚧 В разработке | 🏁 Завершён | 📦 Архив | ⚠️ Требует внимания

## Шаги

**Шаг 1: Найти все кодовые файлы**

```bash
find . -type f \( -name "*.py" -o -name "*.mqh" -o -name "*.mq4" -o -name "*.ipynb" \) \
  ! -path "./.venv/*" ! -path "./__pycache__/*" ! -path "./.git/*" ! -path "./.kilocode/*" | sort
```

**Шаг 2: Извлечь file headers**

Для каждого файла извлечь:
- **Python**: блок `# ===` ... `# ===`
- **MQL4**: блок `//+--` ... `//+--` (кодировка UTF-16LE!)
- **Jupyter**: первую Markdown-ячейку

**Шаг 3: Парсить поля**

| Поле | Из header | Пример |
|------|-----------|--------|
| Назначение | `# Назначение:` / `# Purpose:` | "CLI оркестратор pipeline" |
| Вход | `# Входные данные:` | `Nero.csv` |
| Выход | `# Выходные данные:` | `DATA/Nero_train_labeled.csv` |
| Статус | из текущего MODULE_INDEX.md | ✅ |

Если поле отсутствует в header → поставить `-`.
Статус файла — брать из текущего MODULE_INDEX.md, не выдумывать.

**Шаг 4: Сгенерировать MODULE_INDEX.md**

Структура файла:
- Разделы по директориям (Processing, Statistics, API, MT/MQL4, ML)
- Внутри каждого раздела — таблица с колонками: Модуль, Назначение, Вход → Выход, Docs, Статус
- Секция Docs — таблица документов (Файл, Назначение)
- Легенда статусов в конце
- Дата обновления

**Шаг 5: Показать статистику и запросить подтверждение**

```
📊 СТАТИСТИКА РЕГЕНЕРАЦИИ:

Найдено файлов: 25
С file headers: 23
Без headers: 2 (processing/temp.py, ML/old.py)

Изменения:
+ Добавлено: 3 записи
~ Обновлено: 5 записей
- Удалено: 1 запись (файл не найден)

Применить изменения? (yes/no)
```

Только после подтверждения — записать файл.

## Обработка ошибок

| Ситуация | Действие |
|----------|----------|
| Файл без header | Добавить в отчёт, продолжить |
| Неизвестная кодировка | UTF-8, затем UTF-16LE |
| Неполный header | Использовать доступные поля, остальные `-` |
| Дублирующиеся пути | Обновить существующую запись |
