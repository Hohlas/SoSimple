# File Header Templates and Documentation Standards

## File Header Templates

### Python (.py)

```python
# =============================================================================
# Файл: [filename.py]
# Назначение: [одна строка]
# Язык: Python
# Обновлён: [YYYY-MM-DD]
# Зависимости:
#   Входные данные:
#     - [путь/файл] (откуда: [источник])
#   Выходные данные:
#     - [путь/файл] (куда: [назначение])
# Внешние зависимости:
#   - [библиотека>=версия]
# Использование:
#   [команда запуска]
# Примечания:
#   - [важные ограничения]
# =============================================================================
```

### MQL4 (.mqh/.mq4)

**ВАЖНО**: Файлы MQL4 должны быть в кодировке UTF-16LE!

```cpp
//+------------------------------------------------------------------+
//| Файл: [filename.mqh]
//| Назначение: [одна строка]
//| Язык: MQL4
//| Обновлён: [YYYY-MM-DD]
//| Зависимости:
//|   - [файл.mqh]
//+------------------------------------------------------------------+
```

### Jupyter (.ipynb)

Первая ячейка (Markdown):

```markdown
# [Название]

**Файл**: `path/notebook.ipynb`
**Назначение**: [что делает]
**Обновлён**: YYYY-MM-DD

## Входные/Выходные данные
- **Вход**: [файлы]
- **Выход**: [файлы]
```

## Docstrings (Python)

### Module-level Docstring

Добавить сразу после file header:

```python
"""
Краткое описание модуля (1-2 предложения).

Более детальное описание функциональности, если нужно.
"""
```

### Function and Class Docstrings

```python
def function_name(param: type) -> return_type:
    """
    Краткое описание функции.
    
    Аргументы:
        param: Описание параметра
        
    Возвращает:
        Описание возвращаемого значения
        
    Исключения:
        ExceptionType: Когда возникает
        
    Пример:
        >>> function_name(value)
    """
```

## Языковые соглашения

- ✅ **На русском**: docstrings, комментарии, file headers, документация
- ✅ **На английском**: имена переменных, функций, классов, файлов
- ✅ Комментируй «почему», не «что»
- ✅ НЕ комментируй очевидное

**Примеры:**

```python
# ❌ BAD: Очевидное
def calculate_total(items):
    # Создаём переменную total
    total = 0
    # Цикл по items
    for item in items:
        # Добавляем price к total
        total += item.price

# ✅ GOOD: Объяснение "почему"
def calculate_total(items):
    total = 0
    for item in items:
        # Игнорируем items с отрицательной ценой (возвраты обрабатываются отдельно)
        if item.price > 0:
            total += item.price
```

## Markdown Documentation Template

Создать `docs/[category]/[filename].md`:

```markdown
# Название модуля

## Назначение
[одна строка]

## Входные данные
- **Файл**: `path/to/input.csv`
- **Формат**: [описание]
- **Источник**: [откуда]

## Выходные данные
- **Файл**: `path/to/output.csv`
- **Формат**: [описание]
- **Используется в**: [следующий скрипт]

## Использование
\`\`\`bash
python script.py --input data.csv
\`\`\`

## Примечания
- [особенности]
```

## Quick Reference

| File Type | Header Style | Encoding | Docstring Style |
|-----------|--------------|----------|-----------------|
| *.py | `# ===...===` | UTF-8 | Google-style |
| *.mqh/*.mq4 | `//+--...--+` | **UTF-16LE** | None |
| *.ipynb | Markdown cell | UTF-8 | Google-style |
